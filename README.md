# KDS 구조검토

브라우저에서 바로 도는 단일 파일(HTML/JS) 구조검토 툴.
설치·서버 없이 `index.html` 하나로 동작하며, GitHub Pages로 배포하면 현장 PC·휴대폰에서 URL만으로 쓸 수 있다.

## 검토 항목

| 탭 | 내용 | 적용 기준 |
|---|---|---|
| RC 보 | 휨(복철근 포함) + 전단 | KDS 14 20 20 (4.1, 4.2) / KDS 14 20 22 (4.1~4.3) |
| RC 기둥 P-M | 변형률적합 P-M 상관도 작도 + (Mu, Pu) 판정 | KDS 14 20 20 (4.1.1, 4.1.2, 4.3.2) |
| 철골 보 | 휨(소성·LTB·FLB) + 전단 | KDS 14 31 10 (4.3.2.1.1, 4.3.2.1.2) |
| 철골 기둥 | 휨좌굴 압축강도 | KDS 14 31 10 (4.2.1~4.2.3) |

모든 결과 화면에 **어느 기준의 몇 항·몇 번 식**을 썼는지와 **대입값**을 함께 출력한다.

## 계산 근거

- **KDS 14 20 20 : 2022** 콘크리트구조 휨 및 압축
  - 표 4.1-2 등가직사각형 응력분포 변수 (εcu, η, β1) — 표에 없는 fck는 직선보간
  - 4.1.2(3)(4) 압축지배·인장지배 변형률 한계, 4.1.2(5) 최소허용변형률
  - 식 (4.1-16)(4.1-17) φPn,max, 4.2.2 최소 휨철근, 4.3.2(1) 철근비 제한
- **KDS 14 20 22 : 2022** 콘크리트구조 전단 및 비틀림
  - 4.1.1(4) √fck ≤ 8.4, 식 (4.2-1) Vc, 식 (4.3-3) Vs
  - 4.3.2 간격 제한, 4.3.3(3) 최소 전단철근량, 4.3.4(9) Vs 상한
- **KDS 14 20 10 : 2021** — 4.2.3(2) 강도감소계수, 4.3.3(2) Es = 200,000 MPa
- **KDS 14 31 10** 강구조 부재
  - 표 4.2-2 / 표 4.3-2 판폭두께비, 식 (4.2-1)~(4.2-4) 압축
  - 식 (4.3-1) Cb, (4.3-2)~(4.3-8) 휨, (4.3-85)~(4.3-92) 전단
- **KDS 14 31 05 : 2024** — 표 3.4-1 강종별 판두께 Fy, 표 3.5-1 E = 210,000 MPa

## 검증

RC 단면의 P-M 엔진(`rcpar` / `phif` / `pmc` / 이분법 solver)은 이미 실기 검증을 마친
TI-Nspire CX II CAS용 `rc_vert.py` 와 **동일 알고리즘**이며, 동일 입력에 대해
c / Pn / Mn / εt / φ 가 소수점 4자리까지 일치함을 확인했다.

철골 부재는 손계산으로 대조했다 (SM355 H-600×200×11×17, tf=17 → Fy=345):

```
Lp = 1.76 × 41.77 × √(210000/345) = 1813.9 mm
Lr = 5321.8 mm ,  Lb = 3000 mm  →  식 (4.3-3)
Mn = 987.80 − (987.80 − 599.07) × 0.3381 = 856.35 kN·m
φbMn = 0.90 × 856.35 = 770.7 kN·m
```

## 구현하지 않은 항목

- RC 보 : KDS 14 20 20 (4.2.2(1)) φMn ≥ 1.2Mcr — Mcr 식은 KDS 14 20 30 (식 4.2-2)에 있어 이 툴에 없다. (4.2.2(2))의 면제조건만 판정한다.
- RC 기둥 : 장주효과(4.4), 2축 휨(4.5). Mu는 확대계수휨모멘트를 입력할 것.
- 철골 보 : 웨브 비조밀·세장(4.3.2.1.1.4/5), T형·ㄱ형강, 인장역작용(4.3.2.1.2.3).
- 철골 기둥 : 비틀림·휨비틀림좌굴(4.2.4), 세장판 단면(4.2.7), 조립압축재(4.2.6).

## 알려진 주의사항

- 압연 H형강의 비틀림상수 J 는 필릿을 포함하지 않아 규격표값보다 작게(안전측) 나온다. 규격표값이 있으면 직접 입력한다.
- 압연 H형강의 웨브 h 도 필릿을 공제하지 않은 (H − 2tf) 를 쓴다. h/tw 가 크게 나오므로 안전측이다.
- 압축블록 안에 들어간 철근은 fs 에서 η·0.85fck 를 공제한다(콘크리트 면적 중복 제거).

## 사용

`index.html` 을 브라우저로 열거나, GitHub Pages URL로 접속한다.
외부 라이브러리·네트워크를 쓰지 않으므로 오프라인에서도 동작한다.
