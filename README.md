# KDS 구조검토

브라우저에서 동작하는 HTML/JavaScript 구조검토 도구.
GitHub Pages에서 사용할 수 있다. 오프라인 사용 시 `index.html`, `rc-beam.js`, `rc-beam-ui.js`, `rc-beam-checks.js`, `rc-slab-uplift.js`, `rc-slab-uplift-ui.js`를 같은 폴더에 둔다.

## 메뉴 구성

상위 메뉴 4개와 드롭다운 하위 메뉴로 구성한다. 구현하지 않은 항목은 `준비 중` 배지를 달고 선택할 수 없다.

| 상위 메뉴 | 구현한 하위 메뉴 | 적용 기준 | 준비 중 |
|---|---|---|---|
| 설계하중 | — | — | 설계 하중표, 풍하중, 지진하중 |
| 철근콘크리트 | **보** — 인장철근 자동 배치(최대 3단) + 상부 압축철근, 가닥 수별 φMn, 전단·표피철근, 1m당 물량·금액<br>**기둥** — 변형률적합 P-M 상관도 + (Mu, Pu) 판정<br>**내수압 슬래브** — 독립기초 지지 지하 바닥판의 양압력 휨 철근 검토 | KDS 14 20 20 / 14 20 22 / 14 20 50 / 14 20 30 / 14 20 70 | 1방향 슬래브, 2방향 슬래브, 벽체, 기초 |
| 철골 | **보** — 휨(소성·LTB·FLB) + 전단<br>**기둥** — 휨좌굴 압축강도 | KDS 14 31 10 (4.2.1~4.2.3, 4.3.2.1.1, 4.3.2.1.2) | 볼트 접합부, 용접 접합부 |
| 구조해석 | — | — | 프레임 해석 |

각 결과에서 적용 기준과 계산값을 확인할 수 있다. RC 보는 폭·높이, 주철근·스터럽 규격, 재료강도로 자동 배치한다. 스터럽은 D10/D13/D16을 선택하며, 피복 40 mm와 골재 25 mm는 변경 가능하다. 모서리 철근 위치는 스터럽 굽힘 내면 반지름(D16 이하 2db)을 반영한다. [RC 보의 배치 정책·계산 범위](docs/rc-beam.md)를 참고한다.

## 검증

RC 보 자동 배치 모듈: `node --test tests/*.test.cjs`. 독립 단철근 계산, 다단 평형, 배치 경계·간격·정렬, 오류 입력 및 화면 연결을 검사한다. 이는 전체 구조설계 검증을 대신하지 않는다.

기존 RC 기둥의 P-M 엔진(`rcpar` / `phif` / `pmc` / 이분법 solver)은 이미 실기 검증을 마친
TI-Nspire CX II CAS용 `rc_vert.py` 와 **동일 알고리즘**이며, 동일 입력에 대해
c / Pn / Mn / εt / φ 가 소수점 4자리까지 일치함을 확인했다.

철골 부재는 손계산으로 대조했다 (SM355 H-600×200×11×17, tf=17 → Fy=345):

```
Lp = 1.76 × 41.77 × √(210000/345) = 1813.9 mm
Lr = 5321.8 mm ,  Lb = 3000 mm  →  식 (4.3-3)
Mn = 987.80 − (987.80 − 599.07) × 0.3381 = 856.35 kN·m
φbMn = 0.90 × 856.35 = 770.7 kN·m
```

## 구현하지 않은 항목

- RC 보 : 처짐, 정착, 주철근 균열제어 간격, 내진·시공 상세는 미구현. 하중 미입력으로 소요강도 적합 판정과 최소철근 면제조건은 적용하지 않는다. 최소철근 기본조건 φMn ≥ 1.2Mcr는 검토한다.
- RC 기둥 : 장주효과(4.4), 2축 휨(4.5). Mu는 확대계수휨모멘트를 입력할 것.
- 내수압 슬래브 : 전단(1방향·뚫림 모두), 부력에 대한 부상 안정, 균열폭, 처짐, 정착 상세는 미구현이며 휨 철근만 검토한다. 하중조합 `qu = 1.6×양압력 − 0.9×고정하중`은 KDS 조합식이 아니라 사용자 지정값이다. [상세](docs/rc-slab-uplift.md)
- 철골 보 : 웨브 비조밀·세장(4.3.2.1.1.4/5), T형·ㄱ형강, 인장역작용(4.3.2.1.2.3).
- 철골 기둥 : 비틀림·휨비틀림좌굴(4.2.4), 세장판 단면(4.2.7), 조립압축재(4.2.6).

## 알려진 주의사항

- 압연 H형강의 비틀림상수 J 는 필릿을 포함하지 않아 규격표값보다 작게(안전측) 나온다. 규격표값이 있으면 직접 입력한다.
- 압연 H형강의 웨브 h 도 필릿을 공제하지 않은 (H − 2tf) 를 쓴다. h/tw 가 크게 나오므로 안전측이다.
- 압축블록 안에 들어간 철근은 fs 에서 η·0.85fck 를 공제한다(콘크리트 면적 중복 제거).

## 사용

`index.html` 을 브라우저로 열거나, GitHub Pages URL로 접속한다.
외부 라이브러리·네트워크를 쓰지 않으므로 오프라인에서도 동작한다.

결과 화면의 `PDF로 저장` 버튼은 브라우저 인쇄 대화상자를 연다. 대상을 PDF로 지정하면 입력·결과·근거가 한 문서로 저장된다. 접어 둔 상세 항목은 인쇄하는 동안만 자동으로 펼쳐지고 이후 원래 상태로 돌아간다.

## RC 보 입력 화면

왼쪽에 재료 강도, 단면 정보, 철근 설정을 순서대로 입력하고 오른쪽에서 결과를 확인한다. 좁은 화면에서는 입력 아래에 결과를 표시한다. fck는 드롭다운 또는 21–90 MPa 범위의 직접 입력을 지원하며 기본값은 fck 30 MPa, fy 500 MPa이다. fy는 인장·압축 주철근에 함께 적용하며 fyt는 전단강도에 사용하며 일반 보의 스터럽 강도는 400/500 MPa를 선택한다. 상부 압축철근은 규격과 개수를 입력하며 0가닥이면 미반영한다. 상부 철근의 항복 여부 및 실제 인장·압축 상태는 변형률 적합으로 계산한다. 압축철근 횡지지·정착 상세 검토는 포함하지 않는다.

## 1m당 물량 · 전단 · 표피철근

- 보 폭·높이의 증감 화살표는 50 mm 간격으로 동작한다. 직접 입력도 가능하다.
- 전단: 유효 스터럽 다리 수 2~6개, 종방향 간격, 선택 입력 Vu를 사용한다. φVn, 최소철근량, 최대 간격, Vs 상한을 검토한다. 일반 RC 직사각형 보, 수직 스터럽, 축력·비틀림 없음에 한정한다.
- 표피철근: h > 900 mm에서 양측 인장영역 h/2까지 자동 추가한다. 직접 개수 입력 및 미배치 선택도 가능하며, 부족한 배치는 미달로 표시한다. 표피철근은 물량에 포함하고 φMn에는 산입하지 않는다.
- 물량: 선택 배치의 보 길이 1m당 콘크리트 m³와 철근 tonf를 표시한다. 단가 기본값은 12만원/m³ 및 130만원/tonf이고 수정할 수 있다. 반복 구간의 평균 개산 물량으로, 상세 가공·이음·정착 및 공사비 전체 견적은 아니다.

검사: `node --test tests/*.test.cjs` (31개). 상세 근거와 산정 가정은 [계산 문서](docs/rc-beam.md)를 참고한다.

## 경제적인 배근 표시

사용자 지정 지표 ρ=0.5ρb를 사용한다. ρ=As/(bd)에서 As와 d는 하부 인장철근의 면적 및 면적도심 깊이이며, 표피·압축철근은 As에서 제외한다. 비교 기준은 단철근 직사각형의 ρb=0.85η(fck/fy)β₁ εcu/(εcu+fy/Es), Es=200,000 MPa이다. 콘크리트 계수는 KDS 14 20 20 : 2022 표 4.1-2, 균형변형률은 4.1.2(2)의 정의를 사용한다. 0.5 배수는 KDS 의무 조건이나 최소 공사비 최적화 규칙이 아니라 사용자 지정 경제성 기준이다.

현재 주철근 규격의 대표 배치 중 휨·전단·표피철근 조건 및 입력된 Mu/Vu를 만족하는 후보에서 |ρ−0.5ρb|가 가장 작은 하나를 파란색과 체크로 표시한다. 동률이면 가닥 수가 적은 배치를 선택한다. 후보가 없으면 경제 배치 표시를 하지 않고 입력조건 조정 방향을 안내한다. 최초 화면은 경제 후보를 선택하며 이후 사용자가 선택한 배치는 유지한다.

압축철근을 사용한 경우에도 비교 지표 ρb는 단철근 기준이며 실제 φMn은 복철근 해석값을 사용한다. Mu는 선택 입력이고, 입력하면 경제 후보를 강도로 선별한다. 기존 최소 휨철근 면제조건은 적용하지 않는다. Mu가 없으면 철근 감량·단면 축소의 안전 여부를 확정하지 않는다. 단면 확대·규격 변경 조언은 비교 방향이며 변경 치수에 대한 재설계, 처짐·정착 및 비용 최적화를 수행한 것은 아니다.

표피철근 규격은 화면에서 D10만 사용한다. 단가 입력은 콘크리트 12만원/m³, 철근 130만원/tonf를 기본값으로 하며 물량표 단가와 금액도 만원 단위로 표시한다. 내부 계산은 원 단위로 유지하고 입력을 10,000배 변환하므로 실제 재료비는 단위 변경 전과 동일하다.
