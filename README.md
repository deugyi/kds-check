# KDS 구조검토

브라우저에서 동작하는 HTML/JavaScript 구조검토 도구.
GitHub Pages에서 사용할 수 있다. 오프라인 사용 시 `index.html`, `rc-beam.js`, `rc-beam-ui.js`, `rc-beam-checks.js`, `rc-column.js`, `rc-column-ui.js`, `rc-slab-uplift.js`, `rc-slab-uplift-ui.js`, `steel-section.js`, `steel-beam.js`, `steel-beam-ui.js`, `composite-beam.js`, `composite-beam-ui.js`를 같은 폴더에 둔다.

각 결과에서 적용 기준과 계산값을 확인할 수 있다. RC 보는 폭·높이, 주철근·스터럽 규격, 재료강도로 자동 배치한다. 스터럽은 D10/D13/D16을 선택하며, 피복 40 mm와 골재 25 mm는 변경 가능하다. 모서리 철근 위치는 스터럽 굽힘 내면 반지름(D16 이하 2db)을 반영한다. [RC 보의 배치 정책·계산 범위](docs/rc-beam.md)를 참고한다.

## RC 벽체

철근콘크리트 → **벽체**: 면내 전단 상세식/간편식, 수직·수평 방향별 면외 전단과 축력–휨 단면 내력, 양면 철근 배근도 및 면외 P–M 곡선, 공통 PDF 인쇄. [계산 모델과 범위](docs/rc-wall.md). 실행에 `rc-wall.js`, `rc-wall-ui.js`, 기존 `rc-beam.js`가 필요하다.

## 검증

`node --test tests/*.test.cjs`로 전체 모듈을 검사한다. 독립 단철근 계산, 다단 평형, 배치 경계·간격·정렬, 오류 입력 및 화면 연결을 검사한다. 이는 전체 구조설계 검증을 대신하지 않는다.

RC 기둥의 P-M 엔진은 이미 실기 검증을 마친 TI-Nspire CX II CAS용 `rc_vert.py` 와 **동일 알고리즘**이다.
화면을 다시 만들면서 `index.html` 인라인 스크립트에서 `rc-column.js` 모듈로 옮기기만 했고, 옮기기 전후를 5개
조건(그리드 배근·2단 배근·나선철근 고강도·순수휨·큰 편심)에서 대조해 **상대오차 0**으로 일치함을 확인했다.
기본 단면의 결과값은 `tests/rc-column.test.cjs`에 고정값으로 두어 이후 변경이 값을 옮기면 바로 드러난다.

아래 철골 보 손계산 예제는 J를 직접입력하지 않고 필릿 보정도 하지 않은 이론단면 기준이다. KS 규격표 J를 선택한 화면값과는 구분한다.

## 구현하지 않은 항목

- RC 보 : 처짐, 정착, 주철근 균열제어 간격, 내진·시공 상세는 미구현. Mu·Vu 선택 입력 시 해당 소요강도를 확인한다. 최소철근 면제조건은 적용하지 않는다. 최소철근 기본조건 φMn ≥ 1.2Mcr는 검토한다.
- RC 기둥 : 2축 휨(4.5)은 미구현이며 X·Y축을 각각 독립적으로 검토한다. 장주효과(4.4), 횡구속 강도증가(4.1.1(9)), 전단은 미구현. Mu는 확대계수휨모멘트를 입력할 것. [상세](docs/rc-column.md)
- 내수압 슬래브 : 전단(1방향·뚫림 모두), 부력에 대한 부상 안정, 균열폭, 처짐, 정착 상세는 미구현이며 휨 철근만 검토한다. 요청한 상향 `1.6H−0.9D`와 하향 `1.2D+1.6L`을 선택하거나 함께 비교한다. 전체 설계하중 조합은 별도이다. [상세](docs/rc-slab-uplift.md)
- 철골 보 : 웨브 비조밀·세장(4.3.2.1.1.4/5), T형·ㄱ형강, 약축 휨, 인장역작용(4.3.2.1.2.3). [상세](docs/steel-beam.md)
- 합성보 : 부모멘트 구간(4.5.2(3)), 골데크플레이트(4.5.2(4)), 매입형·충전형 합성부재, 처짐은 미구현. 단순보 정모멘트 구간만 검토한다. [상세](docs/composite-beam.md)
- 철골 기둥 : 비틀림·휨비틀림좌굴(4.2.4), 세장판 단면(4.2.7), 조립압축재(4.2.6).

## 알려진 주의사항

- 비틀림상수 J는 직접입력, KS D 3502 표값, 표 밖 규격의 필릿 보정값, Built-up 얇은판 합산 순으로 해당 조건에 맞게 적용한다. 표 밖 추정값을 일률적으로 안전측이라고 볼 수 없다.
- 압연 H형강의 웨브 h 도 필릿을 공제하지 않은 (H − 2tf) 를 쓴다. h/tw 가 크게 나오므로 안전측이다.
- 압축블록 안에 들어간 철근은 fs 에서 η·0.85fck 를 공제한다(콘크리트 면적 중복 제거).

## 사용

`index.html` 을 브라우저로 열거나, GitHub Pages URL로 접속한다.
외부 라이브러리·네트워크를 쓰지 않으므로 오프라인에서도 동작한다.

결과 화면의 `PDF로 저장` 버튼은 브라우저 인쇄 대화상자를 연다. 대상을 PDF로 지정하면 입력·결과·근거가 한 문서로 저장된다. 접어 둔 상세 항목은 인쇄하는 동안만 자동으로 펼쳐지고 이후 원래 상태로 돌아간다.

## RC 보 입력 화면

왼쪽에 재료 강도, 단면 정보, 철근 설정을 순서대로 입력하고 오른쪽에서 결과를 확인한다. 좁은 화면에서는 입력 아래에 결과를 표시한다. fck는 드롭다운 또는 21–90 MPa 범위의 직접 입력을 지원하며 기본값은 fck 30 MPa, fy 500 MPa이다. fy는 인장·압축 주철근에 함께 적용하며 fyt는 전단강도에 사용하며 일반 보의 스터럽 강도는 400/500 MPa를 선택한다. 상부 압축철근은 규격과 개수를 입력하며 0가닥이면 미반영한다. 상부 철근의 항복 여부 및 실제 인장·압축 상태는 변형률 적합으로 계산한다. 압축철근 횡지지·정착 상세 검토는 포함하지 않는다.

## 1m당 물량 · 전단 · 표피철근

- 보 폭·높이의 증감 화살표는 50 mm 간격으로 동작한다. 직접 입력도 가능하다.
- 전단: 유효 스터럽 다리 수 2~6개, 종방향 간격, 선택 입력 Vu를 사용한다. φVn, 최소철근량, 최대 간격, Vs 상한을 검토한다. 일반 RC 직사각형 보, 수직 스터럽, 축력·비틀림 없음에 한정한다.
- 표피철근: h > 900 mm에서 양측 인장영역 h/2까지 자동 추가한다. 직접 개수 입력 및 미배치 선택도 가능하며, 부족한 배치는 미달로 표시한다. 표피철근은 물량에 포함하고 φMn에는 산입하지 않는다.
- 물량: 선택 배치의 보 길이 1m당 콘크리트 m³와 철근 tonf를 표시한다. 단가 기본값은 12만원/m³ 및 130만원/tonf이고 수정할 수 있다. 반복 구간의 평균 개산 물량으로, 상세 가공·이음·정착 및 공사비 전체 견적은 아니다.

검사: `node --test tests/*.test.cjs`. 상세 근거와 산정 가정은 [계산 문서](docs/rc-beam.md)를 참고한다.

## 경제적인 배근 표시

사용자 지정 지표 ρ=0.5ρb를 사용한다. ρ=As/(bd)에서 As와 d는 하부 인장철근의 면적 및 면적도심 깊이이며, 표피·압축철근은 As에서 제외한다. 비교 기준은 단철근 직사각형의 ρb=0.85η(fck/fy)β₁ εcu/(εcu+fy/Es), Es=200,000 MPa이다. 콘크리트 계수는 KDS 14 20 20 : 2022 표 4.1-2, 균형변형률은 4.1.2(2)의 정의를 사용한다. 0.5 배수는 KDS 의무 조건이나 최소 공사비 최적화 규칙이 아니라 사용자 지정 경제성 기준이다.

현재 주철근 규격의 대표 배치 중 휨·전단·표피철근 조건 및 입력된 Mu/Vu를 만족하는 후보에서 |ρ−0.5ρb|가 가장 작은 하나를 파란색과 체크로 표시한다. 동률이면 가닥 수가 적은 배치를 선택한다. 후보가 없으면 경제 배치 표시를 하지 않고 입력조건 조정 방향을 안내한다. 최초 화면은 경제 후보를 선택하며 이후 사용자가 선택한 배치는 유지한다.

압축철근을 사용한 경우에도 비교 지표 ρb는 단철근 기준이며 실제 φMn은 복철근 해석값을 사용한다. Mu는 선택 입력이고, 입력하면 경제 후보를 강도로 선별한다. 기존 최소 휨철근 면제조건은 적용하지 않는다. Mu가 없으면 철근 감량·단면 축소의 안전 여부를 확정하지 않는다. 단면 확대·규격 변경 조언은 비교 방향이며 변경 치수에 대한 재설계, 처짐·정착 및 비용 최적화를 수행한 것은 아니다.

표피철근 규격은 화면에서 D10만 사용한다. 단가 입력은 콘크리트 12만원/m³, 철근 130만원/tonf를 기본값으로 하며 물량표 단가와 금액도 만원 단위로 표시한다. 내부 계산은 원 단위로 유지하고 입력을 10,000배 변환하므로 실제 재료비는 단위 변경 전과 동일하다.

## 2026-09-10 검증·기능 보완

합성보는 한 줄당 스터드 개수와 보 길이방향 간격, 폭 방향 간격을 입력하고 한쪽 반 경간의 개수로 강도를 산정한다. 입력 상세조건 미달도 종합 결과에 반영한다. 스터드는 이형철근의 공칭단면적 대신 실제 선택 몸체지름(13·16·19·22 mm)의 πd²/4를 사용한다. 내수압 슬래브는 두 하중조합의 상·하부 지배 소요강도를 비교한다. 좁은 화면 입력 배치와 도면 확대, 인쇄용 표 줄바꿈을 보완했다. [검증 기록](docs/validation-20260910.md)을 참고한다.


## BH → RH 대체 검토

철골 > 보 : BH→RH에서 기존 용접 조립 H형강을 RH 후보와 비교한다.
- 기존 BH의 φMn·φVn 이상 또는 입력 Mu·Vu 만족 중 선택한다.
- 공통 Lb·Cb와 하나의 공통 강종을 사용하고, 부재별 판두께에 따른 Fy를 반영한다. Fy는 두 판 중 큰 두께를 적용한다.
- 보유 KS 규격표에서 확인된 78종을 대상으로 하며 높이·폭 상한과 Ix 유지 조건을 선택한다.
- 조건 충족 후보를 개산 kg/m 순으로 정렬한다. RH 중량에는 필릿 면적을 포함하고, 강성·내력 단면성능은 기존 엔진의 판 합산값이다.
- BH는 플랜지·웨브 조밀단면에 한하여 내력 비교한다. 이외 BH는 입력 하중 기준만 제공하며 RH도 비조밀·세장 웨브 후보는 제외한다.
- KDS 14 31 10 4.3.2.1.1.2·3, 4.3.2.1.2.2를 적용하는 기존 엔진을 재사용한다. 확인 자료는 기존 사용자 제공 KDS 원문이며 개인 원문 파일은 저장소에 포함하지 않았다.
- 이는 강축 휨·전단의 후보 선정이다. 실제 처짐·진동·접합·지점 국부강도·스티프너·내진 및 발주 가능성은 별도 확인한다.

검증: `node --test tests/*.test.cjs` (132개). 내력 두 조건, 입력 하중 독립성, 후보 중량 정렬, 강성·치수 조건, 지원범위와 오류 입력을 확인했다.


### RH + 역T 확장

같은 페이지에서 RH 단독 / RH + 하부 역T를 선택할 수 있다. 상부 RH와 역T 원본을 동일 규격으로 조합하여 자동 검색하거나 공통 규격을 직접 선택한다. 사용자가 지정한 가운데 플랜지 제외 모델, 정·부모멘트, 실제 중량 및 접합선 전달력의 계산과 범위는 [RH + 역T 검토 문서](docs/steel-rh-tee.md)를 참고한다.


## 합성 기둥 (SRC / CFT)

합성구조 → 합성 기둥에서 SRC 직사각형, 각형 CFT, 원형 CFT를 선택합니다. KDS 14 31 80:2024에 따른 축압축/양축 휨좌굴, 소성응력분포 휨강도, 양축 축력–휨 조합을 검토합니다. SRC는 강재 Fy≤450 MPa, CFT의 휨·조합은 조밀 단면 범위이며 범위 밖이면 판정을 보류합니다. 입력 Mux/Muy에는 2차 효과가 포함되어야 합니다. 자세한 가정과 독립 검증 예제는 [합성 기둥 계산 근거](docs/composite-column.md)를 참고하세요.

모든 9개 계산기는 동일한 PDF 인쇄 버튼과 공통 입력/결과 스타일을 사용합니다.

합성 기둥은 Ec 자동 산정, 800 mm 기본 단면, SRC의 RH/BH 전환과 스터드 도입부 검토를 지원합니다. 스터드는 단면/길이방향 그림에서 클릭하여 배치 위치를 확인할 수 있습니다. 도입부 외 전단흐름, 콘크리트 파괴 및 용접 상세는 화면에 명시한 범위에 따라 별도 확인이 필요합니다.

## RC 보 프레임 해석

`rc-frame.js`와 `rc-frame-ui.js`를 추가했다. 계수하중 Wu·Pu·Mu를 직접 입력하고, 보 자중은 Wu에 포함한다. 균열 및 강성 저감 없이 전체 단면 EA·EI를 사용한다. [모델·입력·부호·검증](docs/rc-frame.md).


## 1방향 RC 슬래브

철근콘크리트 → **1방향 슬래브**: Mu·Vu 직접 입력 또는 단순지지/양단고정/캔틸레버 등분포하중 자동 계산. 상·하부 휨, 콘크리트 1방향 전단, 최소철근과 균열제어 간격, 수축·온도철근, 두께 참고값, 간격 제안 및 클릭 가능한 배근도를 제공한다. 자중은 자동 가산하지 않는다. 12개 계산기가 공통 PDF 인쇄를 사용한다. [계산 범위](docs/rc-slab-oneway.md).


### 1방향 슬래브 하중·결과 보완

고정/활 등분포하중과 집중활하중·위치를 입력하면 1.4D와 1.2D+1.6L을 자동 비교한다. 두 활하중은 동시 재하하며 자중은 자동 가산하지 않는다. 1단 단순·타단 연속(왼쪽 단순, 오른쪽 회전구속)을 추가했다. 결과 상단에는 상하부 배근·휨내력·전단내력·배력근을 함께 표시하고 수축·온도철근량/최대간격/순간격을 별도 판정한다. 골재 입력은 내부 25 mm로 고정했다.
