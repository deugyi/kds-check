# 철골 기둥 화면

2026-09-11: 공통 카드·입력·결과 스타일에 맞춰 재구성했다. 왼쪽은 재료 강도, 단면 정보, 유효좌굴길이와 소요압축력이며 오른쪽은 H형강 미리보기, 설계압축강도, 단면성능, 판폭두께비, 축별 좌굴 결과와 계산 근거이다. 입력 변경 시 자동 갱신하고, 계산식과 대입값은 펼침 영역에서 확인한다.

## 계산 범위

기존 순수 압축 휨좌굴 식을 `steel-column.js`로 분리했다. KDS 14 31 10 4.2.1~4.2.3의 기존 구현을 유지하며, 축별 KL/r 중 큰 값이 지배한다. Fe = π²E/(KL/r)², 비탄성 구간 Fcr = 0.658^(Fy/Fe)Fy, 탄성 구간 Fcr = 0.877Fe, φcPn = 0.9FcrAg를 사용한다. 단위는 mm·MPa·kN이다.

단면성능은 필릿을 제외한 직사각형 판의 합성값이다. 강종 선택 시 기존 KDS 14 31 05 표 3.4-1 자료의 플랜지 두께별 Fy를 자동 적용하며 읽기 전용으로 표시한다. 직접입력 모드에서는 사용자가 지정한 Fy를 적용한다.

기존 공통 판요소 분류(플랜지 0.56√(E/Fy), 웨브 1.49√(E/Fy))를 유지했다. 세장판은 강도를 판정하지 않는다. 용접 조립 H형강은 별도 판요소 기준 확인이 필요하므로 화면에 참고값으로 표시하며 공통 분류만으로 적합 판정을 제공하지 않는다. 비틀림·휨비틀림좌굴, 세장판, 조립재, 2차 구조해석, 접합부는 포함하지 않는다.

## 검증

- 기존 기본값 H400×400×13×21, Fy345, E210000, KLx=KLy=4000: φcPn = 5987.1 kN, Y축 지배. 독립 산술식과 비교했다.
- X축 지배 전환, 탄성 좌굴 구간, 세장판의 강도 미표시, 소요력 변화, 잘못된 치수·빈 입력을 검사한다.
- 실제 브라우저에서 규격 변경에 따른 Fy 갱신, 즉시 재계산, 오류 시 이전 결과 제거, 카드 배치를 확인했다.


## 강축·약축 휨과 상호작용 (2026-09-11)

입력에 Mux·Muy(kN·m), Lb(mm), Cb를 추가했다. 기본 모멘트는 0, Lb는 4000, Cb는 1이다. 같은 하중조합에서 2차 효과를 반영한 Pu·Mux·Muy를 사용한다. 2차 효과의 자동 증폭은 수행하지 않는다. 대칭 단면의 모멘트는 절댓값을 사용한다. Pu는 압축 0 이상만 지원한다.

- 강축: 기존 `SteelBeam.flexure`의 항복·횡비틀림좌굴·플랜지 국부좌굴을 재사용한다. KS 선택단면의 J 규격값 또는 필릿반경을 전달한다. Lb는 KLx/KLy와 독립 입력이다.
- 약축: 제공된 KDS 14 31 10 원문의 4.3.2.1.1.6 식 (4.3-37~40). Sy=2Iy/B, Mp=min(FyZy, 1.6FySy). 조밀 플랜지는 Mp, 비조밀 플랜지는 Mp와 0.7FySy 사이 선형 보간, 세장 플랜지는 0.69E/(B/2tf)^2 × Sy로 산정한다. 판폭두께비는 표 4.3-2의 돌출폭 B/2를 사용한다. φb=0.90.
- 상호작용: 원문 4.4.1.1 식 (4.4-1/2). a=Pu/Pr, x=|Mux|/Mrx, y=|Muy|/Mry. a≥0.2이면 a+(8/9)(x+y)≤1, a<0.2이면 a/2+x+y≤1. 각 단독 강도 한계도 확인한다. Pr=φcPn, Mrx=φbMnx, Mry=φbMny.
- 적용 범위: 2축대칭 압연 H형강, 압축 비세장판, 강축 조밀 웨브, 0.1≤Iyc/Iy≤0.9. 용접 조립단면은 기존 공통 판요소 분류의 한계 때문에 상호작용 판정을 보류한다. 압축재 비틀림·휨비틀림좌굴은 여전히 별도 검토 대상이다.
- 그래프는 현재 축력에서 x+y의 허용 한계를 표시한다. 입력력의 변화에 따라 자동 갱신되며 구조물 전체의 안정성 판정은 아니다.

기준은 사용자 제공 KDS 원문으로 확인했으며 원문 파일은 저장소에 포함하지 않았다. 검증은 축력비 0.2 경계, 두 식의 각각의 산술값과 허용영역 연속성, 부호 반전, 개별 강도 충족/조합 미달, 약축 항복 상한과 보간, Lb 영향, 적용 범위 밖 판정보류를 포함한다.

상단 메뉴에 합성구조를 신설하고 기존 합성보(t6)를 옮겼다. 합성보 계산과 입력값은 유지한다.
