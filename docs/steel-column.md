# 철골 기둥 화면

2026-09-11: 공통 카드·입력·결과 스타일에 맞춰 재구성했다. 왼쪽은 재료 강도, 단면 정보, 유효좌굴길이와 소요압축력이며 오른쪽은 H형강 미리보기, 설계압축강도, 단면성능, 판폭두께비, 축별 좌굴 결과와 계산 근거이다. 입력 변경 시 자동 갱신하고, 계산식과 대입값은 펼침 영역에서 확인한다.

## 계산 범위

기존 순수 압축 휨좌굴 식을 `steel-column.js`로 분리했다. KDS 14 31 10 4.2.1~4.2.3의 기존 구현을 유지하며, 축별 KL/r 중 큰 값이 지배한다. Fe = π²E/(KL/r)², 비탄성 구간 Fcr = 0.658^(Fy/Fe)Fy, 탄성 구간 Fcr = 0.877Fe, φcPn = 0.9FcrAg를 사용한다. 단위는 mm·MPa·kN이다.

단면성능은 필릿을 제외한 직사각형 판의 합성값이다. 강종 선택 시 기존 KDS 14 31 05 표 3.4-1 자료의 플랜지 두께별 Fy를 자동 적용하며 읽기 전용으로 표시한다. 직접입력 모드에서는 사용자가 지정한 Fy를 적용한다.

기존 공통 판요소 분류(플랜지 0.56√(E/Fy), 웨브 1.49√(E/Fy))를 유지했다. 세장판은 강도를 판정하지 않는다. 용접 조립 H형강은 별도 판요소 기준 확인이 필요하므로 화면에 참고값으로 표시하며 공통 분류만으로 적합 판정을 제공하지 않는다. 비틀림·휨비틀림좌굴, 세장판, 조립재, 압축·휨 상호작용, 접합부는 포함하지 않는다.

## 검증

- 기존 기본값 H400×400×13×21, Fy345, E210000, KLx=KLy=4000: φcPn = 5987.1 kN, Y축 지배. 독립 산술식과 비교했다.
- X축 지배 전환, 탄성 좌굴 구간, 세장판의 강도 미표시, 소요력 변화, 잘못된 치수·빈 입력을 검사한다.
- 실제 브라우저에서 규격 변경에 따른 Fy 갱신, 즉시 재계산, 오류 시 이전 결과 제거, 카드 배치를 확인했다.
