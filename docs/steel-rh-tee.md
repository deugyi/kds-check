# RH + 역T 대체 검토

## 모델의 의미

사용자의 현장 대안 검토 모델을 구현했다. RH 상부 플랜지와 절단 역T 하부 플랜지만 휨 플랜지로 사용한다. RH 하부 플랜지의 돌출부와 모든 필릿은 단면성능 및 내력에서 제외한다. 가운데 플랜지 두께 구간에서도 웨브 중심선을 따라 폭 tw인 재료 경로는 유지한다. 두 부재는 동심 배치되며 전 길이에 걸쳐 연속 접합되어 일체 거동한다고 가정한다.

역T를 만드는 원본 RH 78종을 검색한다. 상부 RH는 사용자가 지정한다. 절단 높이는 각 원본 높이의 절반 또는 직접 입력한 높이이며, 절단선이 양 플랜지의 필릿 사이 직선 웨브에 있어야 한다. 재고·실제 생산 가능성은 이 목록으로 보증하지 않는다.

두 실제 웨브 두께가 다르면 **작은 두께로 전 높이를 통일한 I형 검토 모델**을 만든다. 각 부재의 큰 판두께로 강종표 Fy를 구한 후 두 부재 중 작은 Fy를 전체 검토 단면에 적용한다. 실제 계단형 웨브와 중간 플랜지를 포함한 3플랜지 단면을 직접 해석한 결과가 아니다. 이 축소 모델은 사용자가 요청한 모델링 선택이며, 모든 비대칭 실물 거동에 대해 자동으로 안전측임을 보증하지 않는다.

## 기준과 계산

- 사용자 제공 KDS 14 31 10 원문: [강구조 부재 설계기준](https://docs.google.com/document/d/1DrS6OpEdkF7Z67QSCrRaLa4DWGkHec9-/edit). 개인 원본은 저장소에 복제하지 않았다.
- 휨: 4.3.2.1.1.4, 식 4.3-11~26(1축 대칭, 조밀·비조밀 웨브). 압축플랜지 항복, 횡비틀림좌굴, 국부좌굴, 인장플랜지 항복 중 최솟값.
- 세장 웨브: 4.3.2.1.1.5, 식 4.3-27~36. Rpg, 탄성 좌굴, 국부좌굴 및 인장 항복을 반영한다.
- 양 플랜지가 동일하고 웨브가 조밀하면 기존 4.3.2.1.1.2·3 엔진을 사용하되 용접 H형강의 플랜지 한계폭두께비를 사용한다.
- 표 4.3-2에서 용접 플랜지 λr = 0.95√(kcE/FL), 1축 대칭 웨브 λp = min[λr, (hc/hp)√(E/Fy)/(0.54Mp/My−0.09)²]. My는 양단 중 최초 항복모멘트다. 동일 플랜지는 2축 대칭 웨브 한계값을 쓴다.
- hc는 탄성 중립축에서 압축 플랜지 안쪽까지 거리의 2배다. hp는 소성 중립축 기준이며, 압축 플랜지 내부에 소성 중립축이 놓이면 λp 상한 λr를 사용한다.
- φb = 0.90. 무보강 웨브 전단은 기존 4.3.2.1.2.2 엔진의 kv = 5, Aw = Htw, φv = 0.90. 가운데 플랜지의 웨브 보강 효과나 압연 H형강의 φv = 1.0 특례는 사용하지 않는다.
- 압축 플랜지 Iyc/Iy 범위 0.1~0.9, hc > 0, h/tw < 260, aw ≤ 10을 구현 범위로 제한한다. 범위 밖 단면은 추천하지 않는다.
- 정·부모멘트는 플랜지 역할과 hc, Sxc/Sxt 등을 바꿔 각각 계산한다. ‘모두’ 선택은 같은 목표 모멘트의 절댓값을 두 방향이 각각 만족해야 한다.
- Lb와 Cb는 비교 BH, RH 및 RH+T에 동일 입력을 사용한다. 역곡률·부분 보강·지지조건 변화의 자동 추적은 하지 않는다.

단면성능은 세 직사각형의 면적·도심·평행축 정리를 사용한다. 소성 중립축은 면적을 이등분하고 Zx는 그 축에 대한 면적 1차모멘트의 절댓값 합이다. J는 얇은 직사각형 판 합산이며 Cw는 외곽 두 플랜지 기준이다. 4.3-18은 q = J/(Sxc ho)에 대해 sqrt(q + sqrt(q² + 6.76(FL/E)²)) 형태로 계산하므로 Iyc/Iy ≤ 0.23에 따라 J = 0을 대입해도 유한한 값이 된다. 기준의 반올림 계수(1.95, 6.76) 때문에 이 특수 경우 Lr 좌우에 약 0.171% 차이가 생기는 것을 테스트에 명시했다.

## 물량과 접합

중량은 **가운데 플랜지를 포함한 실제 RH 전체 + 실제 절단 역T**다. RH 필릿 4개와 역T 하부 필릿 2개의 면적을 포함하고 밀도 7,850 kg/m³를 사용한다. 1/2 절단의 역T 중량은 원본 RH 중량의 절반과 일치한다. 절단 잔재와 용접금속·절단 손실은 산입하지 않으며 구매·가공비 최적화는 아니다.

접합선 전달력은 검토 모델에서 접합선 아래 역T의 Q를 구해 q = VQ/I로 표시한다. 단위 kN/m는 수치상 N/mm와 같다. 양면이 균등 분담하는 경우 q/2도 표시한다. 참고 전달축력은 |N| = |MQ/I|다. 비교 내력 모드에서는 BH φMn와 φVn, 하중 모드에서는 입력 Mu와 Vu를 사용한다. 각 최댓값은 반드시 동시 발생하는 하중쌍을 의미하지 않는다.

용접 치수·길이·모재 한계상태·단부 정착·부분 보강 단부·조립 순서·잔류응력·연속 접합을 실제로 확보하는 상세를 설계하거나 적합 판정하지 않는다. 실제 단면의 약축·축력·비틀림·국부하중·내진·처짐·진동과 시공단계는 별도다. 후보의 ‘모델 내력 충족’은 이 문서의 단면 모델과 부재 내력에만 해당한다.

## 검증

`tests/steel-rh-tee.test.cjs`는 단면성능을 깊이 0.01 mm 간격 수치적분과 대조하고, 대칭 단면의 기존 엔진 일치, 플랜지 반전 시 정·부모멘트 교환, 세장 웨브 강도 감소, J=0 분기, 중간 플랜지 제외 및 실제 물량 유지, 절단 범위와 양방향 후보 선정을 확인한다.

수치 대조 단면: H = 800, 상부 200×16, 하부 200×17, tw = 10 mm, Fy = 355 MPa, E = 210,000 MPa, Lb = 3,000 mm, Cb = 1. 상면부터 도심 405.10617 mm, Sxc = 3,427,854.94 mm³, Zx = 4,055,322.5 mm³. Mp = 1,439.63949 kN·m, Lp = 1,324.62049 mm, Lr = 4,767.34684 mm. 식 4.3-12에 따른 Mn = 1,153.58206 kN·m 및 φMn = 1,038.22385 kN·m를 고정 대조한다.

전체 회귀검사: `node --test tests/*.test.cjs`.
