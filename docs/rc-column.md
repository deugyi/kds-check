# RC 기둥 P-M 상관도

직사각형 철근콘크리트 기둥의 축력–휨모멘트 상관도를 변형률 적합으로 작도하고, 입력한 (Mu, Pu)가 상관도 안에 있는지 판정한다.

## 계산 엔진

이 화면의 계산은 **이미 실기 검증을 마친 TI-Nspire CX II CAS용 `rc_vert.py`와 동일한 알고리즘**이다. 화면을 다시 만들면서 알고리즘은 한 줄도 바꾸지 않고 `index.html` 인라인 스크립트에서 `rc-column.js` 모듈로 옮기기만 했다. 옮기기 전후를 5개 조건(그리드 배근·2단 배근·나선철근 고강도·순수휨·큰 편심)에서 대조해 상대오차 0으로 일치함을 확인했으며, 기본 단면의 결과값은 `tests/rc-column.test.cjs`에 고정값으로 박아 두어 이후 변경이 조용히 값을 옮기지 못하게 했다.

## 단면과 배근

- b는 휨축에 직각인 폭, h는 Mu 방향 깊이이다. d는 압축연단부터 잰 거리이다.
- **2단** 방식은 압축철근 As′(깊이 d′)와 인장철근 As(깊이 d) 두 층으로 이상화한다.
- **nx × ny** 방식은 상·하단에 nx개, 중간 각 열에 2개를 두고 d′부터 d까지 ny개 열을 균등 배치한다. 각 열의 면적은 개수 × 철근 1개 단면적이다.
- 철근비 ρ = Ast/Ag가 0.01~0.08을 벗어나거나 겹침이음 한계 0.04를 넘으면 표시한다 (KDS 14 20 20, 4.3.2(1)).

## 단면력

중립축 깊이 c에 대해 도심 기준으로 축력과 모멘트를 합산한다.

- 등가직사각형 응력블록: a = β₁c, 유효깊이 ae = min(a, h), Cc = η·0.85fck·b·ae
- 각 철근층: εs = εcu(c − d)/c, fs = Es·εs (|fs| ≤ fy), Es = 200,000 MPa
- **압축블록 안에 들어간 철근은 fs에서 η·0.85fck를 공제**해 콘크리트 면적 중복을 제거한다.
- εt는 최외단 철근(dt) 위치의 변형률이고 φ는 이 값으로 정한다.

응력블록 변수 εcu·η·β₁는 KDS 14 20 20 표 4.1-2이며 표에 없는 fck는 직선보간한다.

## 주요 검토점

| 검토점 | 정의 |
|---|---|
| 중심축하중 | Po = 0.85fck(Ag − Ast) + fy·Ast, φPn,max = k·φ0·Po |
| 균형변형률 | εt = εy 인 c = εcu·dt/(εcu + εy) (4.1.2(2)) |
| 인장지배 한계 | εt = εtl (4.1.2(4)). fy ≤ 400이면 0.005, 초과하면 2.5fy/Es |
| 순수휨 | Pn = 0이 되는 c를 이분법으로 탐색 |
| 소요점 | 같은 편심 e = Mu/Pu 선상에서 Mn/Pn = e를 만족하는 c |

φPn,max 계수는 횡보강 형식에 따른다 — 띠철근 k = 0.80, φ0 = 0.65 (식 4.1-17), 나선철근 k = 0.85, φ0 = 0.70 (식 4.1-16). 이 절단선이 상관도 상단을 자르며, 소요점의 φPn이 절단선을 넘으면 절단값으로 표시한다.

Pu = 0을 입력하면 편심이 무한대가 되므로 순수휨으로 검토한다.

## 판정

소요점의 φPn·φMn과 입력값을 비교한다. Pu ≤ φPn 이고 Mu ≤ φMn 이면 (Mu, Pu)가 상관도 내부이다. Pu = 0이면 Mu ≤ φMn만 본다.

Pu가 0.10·fck·Ag보다 작으면 4.1.2(5)에 따라 휨부재로 취급할 수 있음을 알린다.

## 구현하지 않은 항목

- **장주효과 (KDS 14 20 20, 4.4)** — 세장비 판정과 모멘트 확대를 하지 않는다. **Mu는 확대계수휨모멘트를 입력해야 한다.**
- **2축 휨 (4.5)** — 한 방향 휨만 검토한다.
- 전단·비틀림, 띠철근·나선철근의 상세와 간격, 정착과 이음, 내진 특수규정
- 단면은 직사각형만 지원하며 철근은 입력한 층으로 이상화한다. 원형 단면, 부정형 단면, 매입형 합성기둥은 대상이 아니다.
- 상관도는 순수휨(Pn = 0)부터 Po까지만 그린다. 순인장 영역은 기둥 검토에 쓰이지 않아 생략했다.
