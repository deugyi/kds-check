# RC 기둥 P-M 상관도

직사각형과 원형 철근콘크리트 기둥의 축력–휨모멘트 상관도를 변형률 적합으로 작도하고, 입력한 (Mu, Pu)가 상관도 안에 있는지 판정한다. 횡보강 상세와 1 m당 물량·재료비를 함께 산정한다.

## 계산 엔진

P-M 해석은 **이미 실기 검증을 마친 TI-Nspire CX II CAS용 `rc_vert.py`와 동일한 알고리즘**이다. 화면과 입력을 개편하면서도 이 해석부는 바꾸지 않았고, 기준 단면의 결과값을 `tests/rc-column.test.cjs`에 소수점 10자리 고정값으로 두어 이후 변경이 값을 옮기면 바로 드러나게 했다. 고정값은 입력 처리부가 아니라 solver를 직접 호출해 검사하므로 입력 방식을 바꿔도 회귀 검사가 유지된다.

## 검토 방향

**두 방향 휨이 동시에 작용하는 2축 휨(4.5)은 다루지 않는다.** 각 축을 **독립적으로** 검토한다.

- **사각기둥** — X축 휨(깊이 h)과 Y축 휨(깊이 b)을 각각 1방향으로 검토한다. 같은 철근 배치를 해당 방향 좌표로 다시 묶어 층 모델을 만들고, 폭과 깊이를 맞바꿔 같은 solver에 넣는다.
- **원형기둥** — 축대칭이므로 휨 방향과 무관하다. 한 번만 검토하며 Mux·Muy 중 큰 값을 쓴다.

## 단면과 배근

주철근은 **총 개수와 행 수**로 위치를 자동 산정한다.

- **사각** — 둘레 배근이다. 상·하단 행에 (총 개수 − 2 × 행수 + 4)/2 개, 중간 각 행에 2개를 두고 행을 깊이 방향으로 균등 배치한다. 총 개수는 짝수여야 하고, 상·하단 행에 2개 이상 남아야 한다.
- **원형** — 원주에 균등 배치한다.
- 철근 중심까지의 거리는 피복 + 횡보강근 지름 + 주철근 지름/2 이다.
- 철근비 ρ = Ast/Ag는 0.01~0.08, 겹침이음 구간은 0.04 이하이다 (4.3.2(1)). 주철근 최소 개수는 띠철근 4개, 나선철근 6개이다 (4.3.2(2)).

## 단면력

중립축 깊이 c에 대해 도심 기준으로 축력과 모멘트를 합산한다.

- 각 철근: εs = εcu(c − d)/c, fs = Es·εs (|fs| ≤ fy), Es = 200,000 MPa
- **압축블록 안에 들어간 철근은 fs에서 η·0.85fck를 공제**해 콘크리트 면적 중복을 제거한다.
- εt는 최외단 철근(dt) 위치의 변형률이고 φ는 이 값으로 정한다.
- 압축영역은 **사각**이면 폭 × min(a, 깊이)의 직사각형, **원형**이면 깊이 a의 활꼴이다. 활꼴은 면적 A = R²·acos(d/R) − d√(R² − d²), 도심 거리 = (2/3)(R² − d²)^{3/2}/A 로 구한다 (d = R − a).

응력블록 변수 εcu·η·β₁는 KDS 14 20 20 표 4.1-2이며 표에 없는 fck는 직선보간한다.

## 주요 검토점

| 검토점 | 정의 |
|---|---|
| 중심축하중 | Po = 0.85fck(Ag − Ast) + fy·Ast, φPn,max = k·φ0·Po |
| 균형변형률 | εt = εy 인 c = εcu·dt/(εcu + εy) (4.1.2(2)) |
| 인장지배 한계 | εt = εtl (4.1.2(4)). fy ≤ 400이면 0.005, 초과하면 2.5fy/Es |
| 순수휨 | Pn = 0이 되는 c를 이분법으로 탐색 |
| 소요점 | 같은 편심 e = Mu/Pu 선상에서 Mn/Pn = e를 만족하는 c |

φPn,max 계수는 횡보강 형식에 따른다 — 띠철근 k = 0.80, φ0 = 0.65 (식 4.1-17), 나선철근 k = 0.85, φ0 = 0.70 (식 4.1-16). Pu = 0이면 순수휨으로 검토한다.

## 횡보강 상세

**상세와 물량만 반영하며 횡구속에 의한 강도·연성 증가(4.1.1(9))는 P-M에 산입하지 않는다.**

- **띠철근** (KDS 14 20 50, 4.4.2(3)) — D32 이하 주철근은 D10 이상, D35 이상은 D13 이상. 수직간격은 축방향 철근지름의 16배, 띠철근 지름의 48배, 단면 최소 치수 중 작은 값 이하.
- **나선철근** (KDS 14 20 20, 4.3.2(3) / KDS 14 20 50, 4.4.2(2)) — ρs ≥ 0.45(Ag/Ach − 1)·fck/fyt. 배치 ρs는 4·Asp/(Dch·s)로 계산한다. fyt ≤ 700 MPa이고 400 MPa 초과 시 겹침이음을 할 수 없다. 순간격 25~75 mm, 지름 10 mm 이상. 원형 단면에만 적용한다.

## 1 m당 물량과 재료비

- 콘크리트 체적 = Ag / 10⁶ m³. 철근 체적을 공제하지 않은 총체적이다.
- 주철근 = Ast × 길이 1 m. 철근 밀도 7,850 kg/m³로 tonf 환산한다.
- 횡보강근 1조 절단길이는 **사각**이면 심부 둘레 2(W + H)에 135° 갈고리 연장 max(6dt, 75 mm) 2개를 더한 개산값, **원형**이면 심부 둘레 1회전 πDch 이다. 조수/m = 1000/간격.
- 합계 = (주철근 + 횡보강근) × (1 + 할증률). 겹침이음·정착·가공 상세와 거푸집·노무·부가세는 별도이다.

## 구현하지 않은 항목

- **2축 휨 (4.5)** — 두 방향 휨이 동시에 작용하는 경우는 다루지 않는다. X축·Y축을 각각 독립적으로 검토할 뿐이다.
- **장주효과 (4.4)** — 세장비 판정과 모멘트 확대를 하지 않는다. **Mu는 확대계수휨모멘트를 입력해야 한다.**
- 횡구속에 의한 강도·연성 증가 (4.1.1(9)), 전단·비틀림, 정착과 이음, 내진 특수규정
- 단면은 직사각형과 원형만 지원한다. 나선철근은 원형 단면에만 적용한다. 사각 나선, 삼각형 띠철근, 부정형 단면, 매입형 합성기둥은 대상이 아니다.
- 주철근 사이의 순간격과 다발철근 여부는 검사하지 않는다.
- 상관도는 순수휨(Pn = 0)부터 Po까지만 그린다. 순인장 영역은 기둥 검토에 쓰이지 않아 생략했다.
