# PRD 시공 현황

## 현장 요약 그래픽 (2026-09-29)

- 승인된 계정으로 조회한 남측 PRD 기록에서 전체 타설 완료율, 천공 기록 수, 타설 완료 수, 잔여 공수, 자재 반입 기록 수를 집계한다. 잔여는 타설일 미입력 공수이며 공정표 대비 지연 판단이 아니다.
- 공구별 완료율 그래프를 클릭하면 기존 공구 도면과 상세표로 이동한다. 요약은 남측 전체 기준이며 도면 검색·선택으로 분모가 바뀌지 않는다. 기록이 바뀌거나 날짜가 바뀔 때 요약을 갱신하고, 공 클릭·확대·이동만 할 때는 다시 그리지 않는다.
- 최근 8주 천공·타설 실적은 한국 날짜 기준 월요일~일요일로 집계한다. 오늘 이후 날짜는 주간 실적에 포함하지 않으며, 전체 누적 수량은 기존 현황표처럼 날짜 입력 여부를 기준으로 한다. 그래프 아래에서 동일한 수치를 표로 확인할 수 있다.
- 요약 패널은 접을 수 있고 도면 전체 화면에서는 숨긴다. 로그아웃 시 요약 내용도 비운다. 북측·다른 공종에는 실제 기록이 없으므로 임의의 수치나 그래프를 표시하지 않는다.

서리풀 : 남측 > PRD는 승인된 Google 계정으로 로그인한 후 Supabase에서 고정 도면과 시공 기록을 불러온다. 파일 선택 및 도면 교체 UI는 제공하지 않는다. 원본 DXF를 수정하지 않고 원/문자/구역 정보만 추출한다.

로그인 설정, 권한, 서버 저장 및 이전 도면의 공개 이력은 [서리풀 로그인 문서](seoripul-login.md)를 참고한다. 초기 공개 배포와 달리 현재 도면 JSON은 정적 호스팅에서 제외한다.

## 지원 범위

- mm 단위 모형 공간의 CIRCLE과 TEXT. 블록/MTEXT/다른 단위는 현재 지원하지 않는다. INSERT가 남으면 경고한다.
- 번호 `-col_number`, 부재명 `-col_name`, 타입 `-col_type`, 반력 `-col_reaction` 레이어. TEXT의 정렬에 따라 삽입점 또는 정렬점을 사용한다.
- `-perimeter`, `-zoning`의 LWPOLYLINE. 닫힘 플래그 또는 일치하는 양 끝점으로 폐합을 판별한다. 곡선은 직선으로 표시하고 경고한다.
- 큰 원본 좌표는 평행이동만 하며 mm 크기를 유지한다. 원 지름과 레이어의 명시 공경은 데이터에서 구분한다. 공별 정보 화면에는 공경 레이어만 표시한다.
- 문자는 가장 가까운 공과 연결한다. 최대 허용거리 밖은 미연결, 거리비가 애매하면 경고한다. 다중 번호/중복 번호/미연결 번호/다중 부재명은 확인 필요로 표시하고 강제로 재배정하지 않는다.

## 기록 및 저장

- 같은 도면 안에서는 DXF 객체 handle로 기록한다. 공 번호가 중복되어도 기록은 섞이지 않는다.
- 기본 도면의 ID는 원본 파일 SHA-256으로 유지한다. 이전 버전의 같은 DXF 기록을 명시적으로 가져올 수 있다. 저장 도면 형상은 사용하지 않고 고정된 기본 도면과 기존 기록을 결합한다.
- 천공 일자, 자재 반입 일자, 타설일(완료일), 메모. 저장 버튼과 다른 공 선택 시 저장한다. 미저장 변경은 창 닫기 전 경고한다.
- 자재 반입이 천공보다 먼저일 수 있다. 타설일(완료일)이 입력된 선행 작업 일자보다 빠르면 저장하지 않는다. 비어 있는 날짜는 추정하지 않는다.
- 상태는 미착수/천공 완료/자재 반입/천공·반입 완료/타설 완료. 타설일(완료일)이 있으면 타설 완료로 표시한다.
- 날짜·메모는 서버에 저장한다. 다른 사용자 변경은 주기적 조회 또는 최신 기록 버튼으로 불러온다. 같은 공의 동시 변경은 버전 충돌로 알리고 입력을 보존한다. 서버 오류 시 저장된 것으로 표시하지 않는다.
- 상단 백업·복원·CSV 메뉴는 사용자 요청으로 제거했다. 기존 브라우저 기록은 같은 도면 ID를 확인해 사용자가 가져오기 버튼으로 이전한다.

## 공구별 상세 현황

- ZONING 경계 10개: A1·A2·A3 / B1·B2·B3 / C1·C2·C3·C4. 사용자 확인에 따라 B4는 생성하지 않는다.
- 고정 도면의 구역선에 공구 이름을 붙이며, 공 번호 문자열이 아닌 공 중심의 다각형 포함 여부로 소속을 판정한다. 현재 790공 모두 하나의 공구에 포함된다.
- 경계 중복 또는 경계 밖 공은 미분류로 표시하며 복수 공구에 중복 합산하지 않는다.
- 공구 영역·이름 또는 공구 버튼 클릭으로 해당 공구를 선택한다. 다른 공구는 흐리게 표시하고, 전체 버튼으로 해제한다. 기존 개별 공 클릭과 지도 이동/확대 기능은 유지한다.
- 오른쪽에 공구 요약, 도면 아래에 공구별 상세 수량과 공별 날짜·메모 목록을 표시한다. 목록의 공 번호로 해당 공을 선택·확대할 수 있다.
- 천공·자재 반입·타설 누적 수량은 각각 날짜가 있는 공 수다. 상태별 5개 수량은 서로 배타적이다. 시공률은 타설일(완료일) 입력 공 수 / 해당 공구 전체 공 수로 계산한다. 검색·상태 필터는 표시 목록만 바꾸고 공구 시공률 분모를 바꾸지 않는다.
- 날짜 저장·삭제 후 현황을 다시 계산한다. 기존 저장 키와 도면 SHA-256 ID를 유지하므로 기존 시공 기록이 이어진다.
- 검사: `node --test tests/prd-zones.test.cjs tests/prd.test.cjs tests/rc-beam-ui.test.cjs tests/report-print.test.cjs`

## 화면 정리 및 전체 화면

- 상단 제목·파일 정보·백업/복원/CSV 메뉴와 고정 안내를 삭제했다. 기존 localStorage 원본은 가져오기 이후에도 보존한다.
- 공별 정보는 공구·부재명·타입·공경 레이어만 표시한다. 객체 번호·반력 원문·도면 원 지름은 데이터에서 삭제하지 않고 표시에서 제외한다.
- 도면 아래 중복 공 번호 버튼 목록은 제거했다. 공구 상세 현황표의 날짜·메모 목록은 유지한다.
- 도면 도구줄의 전체 화면 버튼으로 확대한다. 브라우저 전체 화면이 지원되지 않으면 화면 전체를 채우는 레이아웃으로 대체한다.
- 전체 화면 진입 시 도면이 전체 폭을 차지한다. 공·공구 선택 시 오른쪽 상세 정보를 열며, 상세정보 열기/닫기로 표시를 바꿀 수 있다. 상세 목록 보기는 전체 화면을 종료하고 현황표로 이동한다.
- Esc, 닫기 버튼, 브라우저 전체 화면 종료로 복귀한다. 선택·날짜 입력·줌·이동 상태는 유지한다. 오류는 오류 영역, 저장/입력 상태는 공별 폼에 표시한다.

## 도면 조작 성능

- 같은 공구에서 공만 선택할 때는 이전/새 선택 원과 입력 폼만 갱신한다. 790개 원의 상태와 상세 현황표를 다시 만들지 않는다. 입력 중이던 기록은 기존처럼 먼저 저장하며, 저장 실패 시 선택을 유지한다.
- 번호 정렬과 검색용 문자열은 도면을 불러올 때 준비한다. 공구·필터·기록이 바뀔 때만 현황을 다시 계산하고, 원 속성은 값이 달라진 경우에만 쓴다.
- 이동·휠 확대 요청은 requestAnimationFrame으로 모아 한 프레임에 한 번 SVG viewBox를 갱신한다. 이동 시작 때 좌표 변환을 읽고, 이후에는 시작 위치와 총 이동량으로 계산한다. 이동 중에는 공구 글자 크기를 다시 쓰지 않는다.
- `node --test tests/prd-ui.test.cjs`로 선택 시 두 원만 갱신하는지, 현황표를 보존하는지, 공구/검색/자동 저장/저장 실패 및 이동·휠 연속 이벤트를 확인한다. DOM 어댑터 검사이며 실제 브라우저의 프레임 시간 측정을 대신하지 않는다.
- 브라우저에서 공구·공 선택, 드래그, 버튼·휠 확대, 날짜 저장, 전체 화면을 별도로 확인한다. 기본 도면 ID와 공 기록 키는 유지한다. 저장 위치만 서버로 이전한다.

## 남측·북측 메뉴 (2026-09-29)

- 대메뉴와 메인 목록을 `서리풀 : 남측`, `서리풀 : 북측` 순서로 표시하며 각각 PRD·철골보·슬래브·커튼월을 같은 순서로 제공한다. 커튼월은 시공 현황 기능 준비 안내 페이지다.
- 기존 도면과 시공 기록은 남측에서 그대로 사용한다. 북측은 도면 등록 전까지 준비 안내만 표시하며 남측 도면을 복제하거나 연결하지 않는다.
- 두 현장의 8개 페이지 모두 기존 Google 로그인 및 관리자 승인 정책을 공유한다. 북측에서 로그인하면 선택했던 북측 페이지로 돌아온다. 북측 전용 승인 그룹은 이번 변경에 포함하지 않는다.
- 북측 실제 도면을 연결할 때는 별도 도면 ID와 서버 접근 제어를 적용해야 한다. 현재 북측 페이지에는 비공개 현장 데이터가 포함되지 않는다.


### 전체화면 그래프와 도면 전환 (2026-09-30)

전체화면 도구 모음의 `현황 그래프`로 기존 요약 그래프·주간 실적표를 열고, `도면으로 돌아가기`로 직전 확대 위치를 유지한 도면으로 복귀한다. 공구 탭과 `전체 도면`은 그래프 화면에서도 유지되며, 탭 또는 공구별 그래프를 선택하면 전체화면을 유지한 채 해당 도면 범위로 전환한다. 공구 전환 시 검색/상태 필터를 초기화하고 상세 입력 패널은 닫는다. 공을 선택하면 기존 상세 입력이 열린다.

동일한 대시보드 DOM을 이동해 사용하므로 서버 기록과 권한 흐름은 바뀌지 않는다. 전체화면 종료 시 원래 대시보드 위치와 접힘 상태를 복원하며, 로그아웃 시 전체화면과 그래프를 종료하고 기록을 비운다.


### 현장 통합 페이지 (2026-09-30)

남측(`site-prd`)·북측(`site-north-prd`) 각각 하나의 인증된 시공 현황 페이지에 PRD / 철골보 / 슬래브 / 커튼월 패널을 둔다. 메뉴·홈 진입점도 현장별 `시공 현황` 하나로 통합한다. 공종 드롭다운과 전체화면 버튼은 공통 헤더에 있으며, 전체화면을 종료하지 않고 공종을 전환한다. 북측과 미등록 공종은 준비 중 화면만 제공한다.

`site-workspace.js`는 공종 전환·전체화면·포커스 복원·권한 해제 시 전체화면 종료를 담당한다. 남측 PRD에서 다른 공종으로 이동할 때 미저장 입력을 먼저 서버에 저장하며 실패 시 PRD에 머물러 입력을 보존한다. PRD 도면의 선택 공구·확대 위치·현황 그래프 상태는 공종을 돌아와도 유지한다. 공 번호 검색은 제거하고 공구 선택과 시공 상태 필터는 유지한다. 모든 패널은 기존 `.site-content` 인증 게이트 안에 유지되며 서버 권한과 데이터 구조는 바꾸지 않는다.

### 엑셀 다운로드 (2026-09-30)

공통 헤더의 `엑셀 다운로드`는 남측 PRD의 현재 공구·상태 필터에 해당하는 저장 기록을 `.xlsx`로 내보낸다. 전체 자료는 `전체 도면`과 `전체 상태`를 선택한 후 내려받는다. 공구별 집계 / 공별 기록 / 최근 8주 실적 시트에 같은 범위를 적용하고 기준일·선택 범위·공수를 표시한다. 미입력 날짜는 빈 셀로 유지하며 날짜는 Excel 날짜 형식, 메모는 수식이 아닌 문자열로 쓴다. 다운로드 파일은 저장 시점의 실적 스냅샷이다.

미저장 입력은 다운로드 전에 저장하고 실패하면 생성을 중단한다. 생성 중 공종 전환은 막으며, 권한/계정이 변경되면 파일 다운로드를 취소한다. 북측 및 미등록 공종은 다운로드 버튼을 비활성화한다. 서버 업로드나 새로운 API 없이 브라우저 안에서 생성한다.

### 남측 지하1층 철골보·슬래브 (2026-10-01)

복구 시 프런트엔드 커밋을 되돌려 준비 화면으로 복귀한다. 서버 도면과 신규 기록 테이블은 보존하여 입력 데이터를 잃지 않게 한다. 이 마이그레이션은 기존 PRD 테이블이나 함수를 교체하지 않는다.

### 지하1층 공구 표시·접합부 추가 보완

공구를 PRD와 같은 파란 이름·연한 채움·점선 경계로 표시한다. 선택 공구는 실선과 강조 채움을 사용한다. 지도에서 공구 이름·경계를 클릭하거나 공구 탭에서 전환한다. 객체 클릭은 유지하며 이름·경계 이외의 영역에서는 객체 선택이 우선한다. 미입력 일반 슬래브는 한 가지 회청색을 사용하고, 완료 기록·추가 검토 영역·선택 공구 강조는 별도 상태로 유지한다.

일반 보선의 표시 이름과 색은 보·거더를 구분하지 않는다. 원본 레이어 정보는 보관하되 화면의 분류 기능으로 제공하지 않는다. 기존 중복 삭제 검토는 유지하며 파랑/자홍색은 명시적으로 중복 검토 모드를 선택했을 때만 사용한다. 엑셀에서도 보·거더 혼합 대신 원본 레이어 상이 여부를 표시한다.

첫 정리본의 300 mm 연장 한도를 넘어 남아 있던 틈을 재검토했다. 기존 방향을 유지하고, 가까운 실제 지지선과의 교점 또는 두 자유 끝점이 서로 가장 가까운 연장 교점을 가진 경우만 추가 연결했다. 기존 정리본의 끝점에서 누적 최대 1,000 mm로 제한했고 369개 선·422개 끝점 연장 작업을 수행했다. 선 개수·원래 방향은 보존하고 삭제/회전/트림은 하지 않았다. 불명확한 끝점 243개는 웹의 `미연결 끝점 표시`와 새 DXF의 `CHECK_OPEN_END`로 확인한다.

수정된 선망으로 폐곡선을 다시 추출했다. 공간 중첩률 90%를 넘는 기존 영역 2,837개의 입력 키를 유지했고 나머지 변경 경계에는 새 키를 부여했다. 서버 반영 시 새 도면에 없는 키의 입력 기록이 존재하면 업데이트를 중단하도록 검사하여 기록을 잃지 않게 한다. 도면 ID는 동일한 현장·층의 개정 이력으로 유지한다. 원본과 이전 검토본은 별도 로컬 파일로 보존한다.
# 종합 현황판 및 지하1층 레이어 (2026-10-02)

공종 선택에 `종합 현황판`을 추가했다. 남측은 승인된 사용자에게만 PRD의 타설일(`installed`), 철골보의 설치일(`completed`), 슬래브의 타설일(`completed`) 입력 건수를 각각 전체 도면 대상으로 집계한다. 기존 공구·필터의 선택은 집계에 영향을 주지 않는다. 동일 키는 한 번 집계하고 도면에 없는 기록은 제외한다. 슬래브의 추가 검토 영역은 분모에서 제외한다. 커튼월과 북측은 등록된 데이터가 없어 준비 중으로 표시하며 0%를 만들어내지 않는다. 공종별 단위가 달라 전체 평균을 계산하지 않는다.

전체화면에서도 현황판과 공종 도면을 전환할 수 있다. 전환 전 입력 저장이 실패하면 기존 공종을 유지한다. 현황판은 30초마다 최신 기록을 읽으며, 권한 변경·로그아웃 시 내용과 대기 응답을 폐기한다. 엑셀은 공종별·공구별 두 시트로 내려받고 최신 기록 조회 실패 시 이전 수치를 새 집계로 내보내지 않는다. 공정표는 아직 미등록이므로 계획 진척도·지연·발주일을 산정하지 않는다.

지하1층 개정 도면의 `-beam`, `-girder`, `-beam_sps`는 각각 작은보·큰보·SPS 철골보로 상세정보와 엑셀에 표시한다. 보선 색은 기존 요청에 따라 통일한다. `-sub_structure`는 흐린 배경으로 묶어 그리며 공간 선택 색인에는 넣지 않는다. 도면 맞춤은 `-perimeter`의 경계를 기준으로 하여 배경의 원거리 객체 때문에 도면이 작아지지 않는다. `-zoning`은 기존 공구 이름을 유지한다.

실제 보선의 중복만 제거하며 슬래브 후보 추출을 위한 임시 연결은 보선 또는 정리 DXF에 추가하지 않는다. 확인이 필요한 미세한 평행선은 비교 그룹으로 남긴다. 기존 저장 기록은 위치·방향·겹친 길이로 연결하고, 도면 개정 시 모든 저장 키의 존재를 서버에서 확인하여 하나라도 연결되지 않으면 교체를 중단한다. 실도면과 정리 보고서는 공개 저장소에 포함하지 않는다.

화면 문제 시 이전 공개 소스 커밋으로 되돌릴 수 있다. 도면 개정 롤백은 비공개 이전 문서와 현재 저장 기록의 키를 먼저 대조한 후 진행해야 하며 기록 테이블을 삭제하지 않는다.

큰 도면의 관리용 전송에는 비공개 스키마의 drawing_upload_chunks를 사용한다. RLS를 활성화하고 공개·로그인 사용자 접근을 모두 회수했다. 서버에서 순서대로 결합해 교체 후 해당 전송 조각을 같은 트랜잭션에서 제거한다. 공개 클라이언트는 이 테이블을 사용하지 않는다. 보안 점검의 정책 없음 알림은 의도된 접근 차단이다. 기존 인증 함수·비밀번호 알림은 이번 변경 범위와 무관하며 권한 검사는 기존 RPC와 RLS에서 계속 수행한다.
# 상단 도구 및 철골보 숨김 (2026-10-02)

- PRD 상태 필터, 확대·축소, 도면 맞춤, 전체화면의 그래프·상세정보 및 번호 표시를 공종 선택과 같은 상단 메뉴에 배치했다. 다른 공종에서는 PRD 도구를 숨긴다.
- 관리자는 철골보를 선택한 후 `이 보 숨기기`로 도면에서 제외할 수 있다. `숨긴 보 목록`에서 선택하고 `이 보 복원하기`로 되돌린다. 관리자 전용 `숨긴 보 표시`는 숨긴 선을 점선으로 비교하기 위한 화면 옵션이다.
- 숨김은 삭제가 아니다. 원본 도면과 시공 날짜·규격·메모는 보존하며, 해당 보만 철골보 도면, 진척률 분모·실적 및 엑셀에서 제외한다. 이 동작으로 기존 슬래브 후보 경계를 다시 생성하지는 않는다.
- `site_member_visibility`는 승인된 사용자에게 표시 여부만 제공한다. 관리 기능 및 숨긴 보의 화면상 재표시는 관리자에게만 제공한다. 숨김은 민감한 도형의 서버 접근 차단 기능이 아니다.
- 서버의 `site_set_member_visibility`는 관리자 권한, 실제 도면 부재 존재 여부, 동시 수정 버전을 확인한다. 변경 전후 상태는 외부에 노출되지 않는 감사 테이블에 기록한다. 일반 기록 수정과 숨김의 버전은 독립적이다.
- 자동 슬래브 후보는 보선의 공간 연결로 추정한 영역이다. 틈·중복선, 보 폭 때문에 생기는 가는 폐곡선, 개구부를 실제 슬래브로 오인할 수 있다. 확정 시공 구역이 필요하면 별도 SLAB 폐곡선 또는 검토 후 영역 확정 절차가 필요하다.
