# PRD 시공 현황

서리풀 현장 > PRD에서 ASCII DXF를 사용자가 선택한다. 도면은 브라우저 내부에서만 해석하며 서버, GitHub 저장소로 전송하지 않는다. 제공된 실제 현장 DXF는 소스에 포함하지 않는다.

## 지원 범위

- mm 단위 모형 공간의 CIRCLE과 TEXT. 블록/MTEXT/다른 단위는 현재 지원하지 않는다. INSERT가 남으면 경고한다.
- 번호 `-col_number`, 부재명 `-col_name`, 타입 `-col_type`, 반력 `-col_reaction` 레이어. TEXT의 정렬에 따라 삽입점 또는 정렬점을 사용한다.
- `-perimeter`, `-zoning`의 LWPOLYLINE. 닫힘 플래그 또는 일치하는 양 끝점으로 폐합을 판별한다. 곡선은 직선으로 표시하고 경고한다.
- 큰 원본 좌표는 평행이동만 하며 mm 크기를 유지한다. 원 지름과 레이어의 명시 공경을 구분해 표시한다. 반력은 단위 추정 없이 원문으로 표시한다.
- 문자는 가장 가까운 공과 연결한다. 최대 허용거리 밖은 미연결, 거리비가 애매하면 경고한다. 다중 번호/중복 번호/미연결 번호/다중 부재명은 확인 필요로 표시하고 강제로 재배정하지 않는다.

## 기록 및 저장

- 같은 도면 안에서는 DXF 객체 handle로 기록한다. 공 번호가 중복되어도 기록은 섞이지 않는다.
- 파일 SHA-256으로 도면을 구분한다. 수정된 DXF는 별도 도면으로 취급하며 이전 기록을 자동 이관하지 않는다. 동일 내용 DXF는 저장된 기록을 다시 읽는다.
- 천공 일자, 자재 반입 일자, 자재 시공 일자, 메모. 저장 버튼과 다른 공 선택 시 저장한다. 미저장 변경은 창 닫기 전 경고한다.
- 자재 반입이 천공보다 먼저일 수 있다. 시공 일자가 입력된 선행 작업 일자보다 빠르면 저장하지 않는다. 비어 있는 날짜는 추정하지 않는다.
- 상태는 미착수/천공 완료/자재 반입/천공·반입 완료/시공 완료. 시공 일자가 있으면 시공 완료로 표시한다.
- localStorage는 현재 브라우저/사이트에 한정된다. 다른 사용자·기기·여러 탭 사이 실시간 공동 편집은 지원하지 않는다. 브라우저 데이터 삭제 시 사라지므로 JSON 백업을 권장한다. 저장 공간 부족은 화면 오류로 안내한다.
- JSON 백업에는 도면과 모든 기록이 함께 포함된다. 복원 시 형식·공 식별자·날짜를 검사하고 기존 동일 도면 기록 교체는 확인을 받는다.
- CSV는 전체 공의 현황을 내보낸다. UTF-8 BOM, 따옴표 이스케이프 및 수식 시작문자 방어를 적용한다.

## 확인

`node --test tests/prd.test.cjs tests/rc-beam-ui.test.cjs tests/report-print.test.cjs`

실제 제공 도면은 별도로 로컬 검증: 공 790개, 구역/외곽선 11개, 확인 필요 9공. 현장 원본/입력 기록은 테스트 또는 공개 저장소에 포함하지 않는다.
