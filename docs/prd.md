# PRD 시공 현황

서리풀 현장 > PRD는 최초 제공된 DXF를 변환한 `prd-default.json`을 기본 도면으로 자동 표시한다. 파일 선택 및 도면 교체 UI는 제공하지 않는다. 원본 DXF를 수정하지 않고 원/문자/구역 정보만 추출한다. 공개 사이트에 이 파일을 배포하면 도면 정보도 공개된다.

사용자가 기본 도면 정보를 현재 공개 사이트에 포함하는 것에 동의했다. 기본 데이터에는 시공 날짜·메모 등 개인 입력 기록을 포함하지 않는다.

## 지원 범위

- mm 단위 모형 공간의 CIRCLE과 TEXT. 블록/MTEXT/다른 단위는 현재 지원하지 않는다. INSERT가 남으면 경고한다.
- 번호 `-col_number`, 부재명 `-col_name`, 타입 `-col_type`, 반력 `-col_reaction` 레이어. TEXT의 정렬에 따라 삽입점 또는 정렬점을 사용한다.
- `-perimeter`, `-zoning`의 LWPOLYLINE. 닫힘 플래그 또는 일치하는 양 끝점으로 폐합을 판별한다. 곡선은 직선으로 표시하고 경고한다.
- 큰 원본 좌표는 평행이동만 하며 mm 크기를 유지한다. 원 지름과 레이어의 명시 공경을 구분해 표시한다. 반력은 단위 추정 없이 원문으로 표시한다.
- 문자는 가장 가까운 공과 연결한다. 최대 허용거리 밖은 미연결, 거리비가 애매하면 경고한다. 다중 번호/중복 번호/미연결 번호/다중 부재명은 확인 필요로 표시하고 강제로 재배정하지 않는다.

## 기록 및 저장

- 같은 도면 안에서는 DXF 객체 handle로 기록한다. 공 번호가 중복되어도 기록은 섞이지 않는다.
- 기본 도면의 ID는 원본 파일 SHA-256으로 유지한다. 이전 버전에서 같은 DXF를 불러와 저장한 기록은 그대로 연결된다. 저장 도면 형상은 사용하지 않고 고정된 기본 도면과 기존 기록을 결합한다.
- 천공 일자, 자재 반입 일자, 자재 시공 일자, 메모. 저장 버튼과 다른 공 선택 시 저장한다. 미저장 변경은 창 닫기 전 경고한다.
- 자재 반입이 천공보다 먼저일 수 있다. 시공 일자가 입력된 선행 작업 일자보다 빠르면 저장하지 않는다. 비어 있는 날짜는 추정하지 않는다.
- 상태는 미착수/천공 완료/자재 반입/천공·반입 완료/시공 완료. 시공 일자가 있으면 시공 완료로 표시한다.
- localStorage는 현재 브라우저/사이트에 한정된다. 다른 사용자·기기·여러 탭 사이 실시간 공동 편집은 지원하지 않는다. 브라우저 데이터 삭제 시 사라지므로 JSON 백업을 권장한다. 저장 공간 부족은 화면 오류로 안내한다.
- JSON 백업에는 도면과 모든 기록이 함께 포함된다. 복원 시 같은 기본 도면의 ID인지 확인한 뒤 기록만 적용한다. 다른 도면의 백업은 거부하고, 기본 도면 형상은 백업으로 바꾸지 않는다. 기록 교체는 확인을 받는다.
- CSV는 전체 공의 현황을 내보낸다. UTF-8 BOM, 따옴표 이스케이프 및 수식 시작문자 방어를 적용한다.

## 확인

`node --test tests/prd.test.cjs tests/rc-beam-ui.test.cjs tests/report-print.test.cjs`

실제 제공 도면 로컬 검증: 공 790개, 구역/외곽선 11개, 확인 필요 9공. 기본 데이터에는 사용자 시공 기록을 넣지 않는다. 원본 절대좌표 원점도 포함하지 않는다.

## 공구별 상세 현황

- ZONING 경계 10개: A1·A2·A3 / B1·B2·B3 / C1·C2·C3·C4. 사용자 확인에 따라 B4는 생성하지 않는다.
- 고정 도면의 구역선에 공구 이름을 붙이며, 공 번호 문자열이 아닌 공 중심의 다각형 포함 여부로 소속을 판정한다. 현재 790공 모두 하나의 공구에 포함된다.
- 경계 중복 또는 경계 밖 공은 미분류로 표시하며 복수 공구에 중복 합산하지 않는다.
- 공구 영역·이름 또는 공구 버튼 클릭으로 해당 공구를 선택한다. 다른 공구는 흐리게 표시하고, 전체 버튼으로 해제한다. 기존 개별 공 클릭과 지도 이동/확대 기능은 유지한다.
- 오른쪽에 공구 요약, 도면 아래에 공구별 상세 수량과 공별 날짜·메모 목록을 표시한다. 목록의 공 번호로 해당 공을 선택·확대할 수 있다.
- 천공·자재 반입·시공 누적 수량은 각각 날짜가 있는 공 수다. 상태별 5개 수량은 서로 배타적이다. 시공률은 자재 시공 일자 입력 공 수 / 해당 공구 전체 공 수로 계산한다. 검색·상태 필터는 표시 목록만 바꾸고 공구 시공률 분모를 바꾸지 않는다.
- 날짜 저장·삭제, 백업 복원 후 현황을 다시 계산한다. 기존 저장 키와 도면 SHA-256 ID를 유지하므로 기존 시공 기록이 이어진다. CSV 전체 현황표에 공구 열을 추가한다.
