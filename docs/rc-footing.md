# 사각형 독립기초 · 지내력 / 파일

중앙 사각형 기둥을 지지하는 일정 두께 기초. 단위 mm, MPa, kN, kN·m. 정상중량 콘크리트 24 kN/m³. 사용 축력·모멘트와 계수 축력·모멘트를 별도로 입력한다. 기둥 하중에서 기초 자중은 제외하고, 프로그램이 사용하중에는 1.0, 계수하중에는 선택한 계수를 곱하여 가산한다. 상재하중은 현재 범위 밖이다.

## 반력과 단면력
- 지내력: 총 사용 접지압과 입력 허용지내력을 비교. 강체, 전면 압축 접촉의 선형 압력 N/A + My x/Iy + Mx y/Ix. 사용 또는 계수 접지압에 인장이 있으면 결과를 중단한다.
- 파일: 동일 축강성, 대칭 2~6 × 2~6 격자. R = N/n + My x/Σx² + Mx y/Σy². 인발을 허용하지 않는다. 입력 허용지지력은 사용반력과 비교한다.
- 휨: 기둥면 외측 순반력의 모멘트. 1방향 전단: 기둥면 d 외측 순반력. 반력에 포함된 기초 자중을 해당 구역에서 차감한다.
- 파일이 전단 위험단면에 걸치면 KDS 14 20 70 4.2.2.2(4)에 따라 직경 범위에서 선형 보간한다. 뚫림 사각 둘레의 모서리에 걸친 파일은 두 면 외측 분담을 더해 1 이하로 제한한다. 모서리 중복을 공제하지 않는 보수적 상한이다.
- X 철근은 최하단, Y는 바로 위. 전폭 균등 배근. 직사각형 단변방향은 중앙대 철근 분담 2/(β+1)을 확보하도록 단위폭 모멘트에 2β/(β+1)을 곱한다.
- 휨은 기존 검증된 RCSlabUplift.capacity의 변형률 적합과 강도감소계수 사용. 반대 부호 휨은 하부 철근만으로 통과시키지 않는다. 최소철근은 ρmin bh를 사용하며 1800 mm²/m 상한을 적용하지 않는 보수적 검토. 간격은 min(2h,300) 이하.
- 1방향 전단은 KDS 간편식 φVc = 0.75 min(√fck,8.4) b d / 6. 전단보강 없음.

## 기둥 주변 2방향 전단
KDS 14 20 22:2022 4.11.2. 위험둘레는 기둥면 d/2, d는 X/Y 중 작은 값. 위험둘레가 기초 경계를 벗어나면 계산 중단.

Vc = vc b₀ d; vc = ks kbo fte cotψ cu/d (λ=1).
ks = (300/d)^0.25, 0.75~1.1; kbo = min(1.25, 4/√(b₀/d)), 내부기둥 αs=1.
fte = 0.2√fck; fcc=2fck/3; cotψ=√(fte(fte+fcc))/fte.
cu=d[25√(ρ/fck)-300ρ/fck]. ρ는 균등배근 X/Y 철근비 평균, 0.005~0.03.
Vc 상한 0.58 fck b₀ cu, 전단 φ=0.75.
지반반력 공제는 d/2 내부만 사용하며 기초 0.75d 특례에 의한 추가 공제는 쓰지 않는다.

모멘트가 있으면 전체 Mx/My를 둘레의 선형 편심 전단응력으로 부담시키는 보수적 예비 검토를 병기한다. 최대응력 = |Vu|/(b₀d)+|Mx|hy/(2Jx)+|My|hx/(2Jy), Jx=d(hx hy²/2+hy³/6), Jy=d(hy hx²/2+hx³/6). 전단 허용응력은 0.75 min(vc,0.63√fck,0.25fck). KDS 4.11.7의 휨·전단·비틀림 분담에 의한 상세 모멘트 전달 설계의 구현을 의미하지 않는다.

## 미포함 항목 / 판정 제한
파일 주변 국부 뚫림 및 군파일 위험둘레, 스트럿-타이, 파일 두부 정착 및 군효과, 상부 배근 설계, 정착길이, 기둥 지압·다월, 침하·활동·전체 안정은 별도 검토. 특히 KDS 14 20 70 4.2.2.2(3)에 해당하는 깊은 파일캡에는 스트럿-타이 검토가 추가로 필요하다. 화면은 계산된 항목만 판정하며 기초 전체의 적합을 선언하지 않는다.
