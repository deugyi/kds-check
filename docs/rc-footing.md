# 사각형 독립기초 · 지내력 / 파일

중앙 사각형 기둥을 지지하는 일정 두께 기초. 단위 mm, MPa, kN, kN·m. 정상중량 콘크리트 24 kN/m³. 화면에서는 사용 축력 Ps와 계수 축력 Pu만 입력한다. 중앙 기둥의 모멘트 전달은 0으로 가정한다. 기둥 하중에서 기초 자중은 제외하고, 프로그램이 사용하중에는 1.0, 계수하중에는 기존 기본값 1.2를 곱하여 가산한다. 상재하중은 현재 범위 밖이다.

## 반력과 단면력
- 지내력: 총 사용 접지압과 입력 허용지내력을 비교. 강체, 전면 압축 접촉의 선형 압력 N/A + My x/Iy + Mx y/Ix. 사용 또는 계수 접지압에 인장이 있으면 결과를 중단한다.
- 파일: 동일 축강성, 대칭 2~6 × 2~6 격자. R = N/n + My x/Σx² + Mx y/Σy². 인발을 허용하지 않는다. 입력 허용지지력은 사용반력과 비교한다.
- 휨: 기둥면 외측 순반력의 모멘트. 1방향 전단: 기둥면 d 외측 순반력. 반력에 포함된 기초 자중을 해당 구역에서 차감한다.
- 파일이 전단 위험단면에 걸치면 KDS 14 20 70 4.2.2.2(4)에 따라 직경 범위에서 선형 보간한다. 뚫림 사각 둘레의 모서리에 걸친 파일은 두 면 외측 분담을 더해 1 이하로 제한한다. 모서리 중복을 공제하지 않는 보수적 상한이다.
- X 철근은 최하단, Y는 바로 위. 전폭 균등 배근. 직사각형 단변방향은 중앙대 철근 분담 2/(β+1)을 확보하도록 단위폭 모멘트에 2β/(β+1)을 곱한다.
- 휨은 기존 검증된 RCSlabUplift.capacity의 변형률 적합과 강도감소계수 사용. 반대 부호 휨은 하부 철근만으로 통과시키지 않는다. 최소철근은 ρmin bh를 사용하며 1800 mm²/m 상한을 적용하지 않는 보수적 검토. 간격은 min(2h,300) 이하.
- 1방향 전단은 KDS 간편식 φVc = 0.75 min(√fck,8.4) b d / 6. 전단보강 전 콘크리트 내력이며, 부족 시 아래 자동 배치를 적용한다.

## 기둥 주변 2방향 전단
KDS 14 20 22:2022 4.11.2. 위험둘레는 기둥면 d/2, d는 X/Y 중 작은 값. 위험둘레가 기초 경계를 벗어나면 계산 중단.

Vc = vc b₀ d; vc = ks kbo fte cotψ cu/d (λ=1).
ks = (300/d)^0.25, 0.75~1.1; kbo = min(1.25, 4/√(b₀/d)), 내부기둥 αs=1.
fte = 0.2√fck; fcc=2fck/3; cotψ=√(fte(fte+fcc))/fte.
cu=d[25√(ρ/fck)-300ρ/fck]. ρ는 균등배근 X/Y 철근비 평균, 0.005~0.03.
Vc 상한 0.58 fck b₀ cu, 전단 φ=0.75.
지반반력 공제는 d/2 내부만 사용하며 기초 0.75d 특례에 의한 추가 공제는 쓰지 않는다.

모멘트가 있으면 전체 Mx/My를 둘레의 선형 편심 전단응력으로 부담시키는 보수적 예비 검토를 병기한다. 최대응력 = |Vu|/(b₀d)+|Mx|hy/(2Jx)+|My|hx/(2Jy), Jx=d(hx hy²/2+hy³/6), Jy=d(hy hx²/2+hx³/6). 전단 허용응력은 0.75 min(vc,0.63√fck,0.25fck). KDS 4.11.7의 휨·전단·비틀림 분담에 의한 상세 모멘트 전달 설계의 구현을 의미하지 않는다.

## 미포함 항목 / 판정 제한
파일 주변 국부 뚫림 및 군파일 위험둘레, 스트럿-타이, 파일 두부 정착 및 군효과, 상부 배근 설계, 정착길이, 기둥 지압·다월, 침하·활동·전체 안정은 별도 검토. 특히 KDS 14 20 70 4.2.2.2(3)에 해당하는 깊은 파일캡에는 스트럿-타이 검토가 추가로 필요하다. 화면은 계산된 항목만 판정하며 기초 전체의 적합을 선언하지 않는다.

## 자동 전단 보강 (2026-09-12)
전단철근 D10/D13/D16 및 fyt 400/500 MPa 선택. 주철근 유효깊이에 선택 전단철근 직경을 차감하여 외면 피복을 확보한다. 추가 철근이 없어도 이 공간을 유보한다.

### 1방향
Vu > φVc인 방향마다 독립적인 2다리 폐쇄형 스터럽 격자를 전폭·전길이에 제안한다. Av,req = max((Vu/φ−Vc)s/(fyt d), max(0.0625√fck,0.35)b s/fyt). Vs = Av fyt d/s. Vs 상한 0.2(1−fck/250)fck b d. 간격은 min(d/2,600), Vs > √fck b d/3이면 절반으로 줄인다. 실제 배치 간격으로 재검산한다. 폭 방향 다리 간격도 min(d,600) 이내로 제한한다. 제안 간격 후보는 300,250,200,150,125,100,75 mm. 배치불가 또는 콘크리트 한도 초과는 미충족이다.

### 뚫림
KDS 14 20 22 §4.11.3: d ≥ 150 mm 및 16db, fs=0.5 min(fyt,400). 첫 열은 s/2, 열 간격 s ≤ d/2, 둘레 방향 다리 간격 ≤ 2d. Vs=Av fs d/s. 공칭강도 상한 0.58 fck b₀ cu. 기존 편심응력 보수적 모델의 비틀림 상한도 유지한다.

보강안 산정은 모든 둘레에 총 계수축력(기초 자중 포함)과 전체 모멘트를 적용하며 반력 공제를 전혀 사용하지 않는다. 따라서 기존 무보강 결과보다 보강 설계용 요구가 클 수 있다. 여러 보강 구간의 요구 Av 최댓값을 모든 열에 동일하게 제공한다. 마지막 열에서 d/2 외측에 전단철근이 없는 위험둘레를 두고, 그 콘크리트 내력이 충족되는 경우만 제안한다. 외곽 둘레까지 기초 안에 들어오지 않으면 단면 확대를 요구한다.

### 도면과 상세 조건
점은 수직 다리이며 X/Y 전용 보강과 뚫림 전용 보강은 따로 산정하고 내력을 중복 사용하지 않는다. 1방향은 인접 2다리를 폐쇄형 스터럽 한 조로 묶는다. 뚫림 각 열의 다리는 상하 휨철근을 감싸 충분히 정착하는 조건이다. 화면 배치는 구조 배근 제안으로, 상부 정착용 철근, KDS 14 20 52 정착 상세, 다리 간 간섭 조정 및 파일 두부 간섭 검토를 완료한 시공 상세도가 아니다. 기존 파일캡 스트럿-타이·국부 뚫림 범위 제한은 유지한다.

## 위험둘레 표시 및 파일 배치 간격 (2026-09-12)
주황 d/2 둘레는 전단 검토선으로, 내부에 전단철근을 배치할 수 없다는 뜻이 아니다. 첫 열은 기둥면에서 d/2 이내에 위치한다. 보강안이 있으면 최외곽 철근에서 d/2 밖의 무보강 검토선도 보라색으로 표시한다.
KDS 11 50 15 §4.1.5.2(2) 원문을 KCSC API로 확인했다. 파일 중심 간격 2.5D 이상, 기초측면부터 파일 중심까지 1.25D 이상을 X/Y 양방향 각각 판정한다. D는 파일 직경이며 유효깊이 d와 다르다. 시설물별 기준에 의한 예외는 자동 적용하지 않는다. 기준 미달이어도 현재 배치 반력은 표시하지만, 배치 간격을 별도 미충족으로 명시한다. 제안 최소 기초 치수는 중심 간격을 max(현재 간격,2.5D)로 하고 양끝 1.25D를 더한 뒤 50mm 단위 올림한다.
공식 기준: https://www.kcsc.re.kr/standardCode/viewer/KDS%2011%2050%2015

## 파일 개수 기반 자동 기초 크기
파일 페이지는 가로·세로를 직접 입력하지 않는다. X/Y 개수, 파일 직경 D, 중심간격 배수 k(기본 2.5, 하한 2.5)를 입력한다. sx=sy=kD; Bx=(nx−1)sx+2×1.25D, By=(ny−1)sy+2×1.25D를 각각 50 mm 단위 올림한다. 면적·기초 자중·사용/계수 반력·휨 및 전단은 이 실제 자동 치수로 재계산한다. 두께는 별도 입력이며, 자동 평면 크기가 모든 구조 내력을 보장하는 것은 아니다. 계산 엔진의 수동 치수 경로는 회귀검증용으로 유지하고, 파일 화면은 autoSize 경로만 사용한다.

## 총개수 기반 배치
파일 화면은 3~36본의 총개수 하나로 배치한다. 3본은 도심을 맞춘 삼각형, 5본은 중앙+4본 배치. 그 외는 양축 대칭을 유지하는 행별 개수 후보를 탐색한다. 후보 점수는 기초 면적 × [1+0.75(장단변비−1)]로, 이 구현에서 탐색한 후보 내에서 작은 면적과 정사각형 유사도를 함께 고려한다. 전역 최적화 또는 안정성 판정을 뜻하지 않는다. 배치 도심은 기둥 중심이며 Σxy=0을 유지하므로 기존 양축 반력식에 좌표를 그대로 사용한다. 각 파일의 실제 좌표로 모든 쌍의 최소간격과 각 축 가장자리 거리를 확인한다. 1~2본 배치는 양축 모멘트 전달 모델의 범위 밖이다. 기초는 여전히 사각형이고, 말뚝군의 실제 좌표 범위에 양끝 1.25D를 더하여 50mm 단위 올림한다.

## 축력 전용 화면과 하부 자동 배근 · 2026-09-15

- 지내력·파일 화면의 기둥 하중 입력은 Ps/Pu만 제공한다. 기둥 모멘트와 자중계수 선택은 제거했다. 기초 자중은 입력 축력에서 제외하고, 사용 총 축력 = Ps + W, 계수 총 축력 = Pu + 1.2W로 계산한다. 이 고정 자중계수와 입력 조건을 화면에 표시한다. 상재하중은 포함하지 않는다.
- 기둥 접합부에서 모멘트를 전달하지 않는 중심 압축 모델이다. 기초판의 휨을 단순지지 보의 wL²/8로 변경하는 의미가 아니다. 기둥면 외측 지반·파일 순반력에 대한 모멘트와 위험단면 전단력을 유지한다.
- 주철근 입력을 제거하고, 슬래브와 같은 D10/D13/D16/D19/D22/D25, @100–@300의 10 mm 간격 후보를 검색한다. X/Y 하부근에 공통 간격을 적용하며 방향별 직경은 달라도 된다. 휨강도·최소철근량·연성·간격 조건을 만족하는 조합 중 단위면적당 X/Y 철근량 합계가 최소인 안을 고른다. 동률이면 넓은 간격을 우선한다. 전단철근을 포함한 총 공사비 최적화는 아니다.
- 기존 최소철근 정책(ρmin bh, 1800 mm²/m 상한 생략)과 min(2h,300) 간격 한도를 유지한다. 직사각형의 단변 방향 중앙대 요구량도 유지한다. KCSC KDS 14 20 70 §4.2.2.1 원문을 재확인했다.
- 선정 직경으로 X 최하단/Y 바로 위의 유효깊이를 산정하고, 1방향 전단·기둥 주변 뚫림 및 자동 전단 보강을 다시 계산한다. 기존 전단 보강 후보와 상세 제한은 유지한다. 요청한 @100–@300 규칙은 하부 주철근에 적용되며 전단철근의 간격 제한을 대신하지 않는다.
- 결과 상단과 평면도에 선정 하부 철근을 표시한다. 주철근 충족과 지지력·전단·유효깊이 판정은 구분한다. 범위 내 주철근 선정이 불가능하면 이전 결과를 지우고 두께/하중/형상 조정을 안내한다. 상부 휨철근 및 전단철근의 상부 정착용 철근 설계는 종전과 같이 별도 상세검토 대상이다.
- `RCFooting.design`은 입력된 다른 이름의 하중·모멘트·수동 배근을 자동설계에 전용하지 않는다. 검증용 `calculate`의 기존 양축 모멘트 경로는 유지하여 기존 평형·부호·전단 회귀검사를 계속 수행한다.

검증: 중심 지반반력의 독립 휨 해, 응력블록으로 독립 확인한 최소량 배근, 공통 간격 및 최종 철근 직경에 따른 d/전단 재계산, 3/5/7/8/12/36본 파일 반력 평형, 하중 증가와 주철근 변화, 자동 전단보강 연결, 잘못된 입력/후보 없음 시 기존 출력 제거, 양쪽 화면 연동.

## 파일 중심거리 표시 · 2026-09-15
5본 배치는 기존과 같이 중앙과 모서리 사이의 대각선 길이를 kD로 배치한다. 모서리 좌표는 (±kD/√2, ±kD/√2)이고, D=500 mm, k=2.5이면 대각선 1250 mm, 각 축 투영거리 약 883.9 mm이다. 평면 치수는 약 3017.8 mm를 50 mm 단위 올림한 3050×3050 mm로 유지한다.
기존 X/Y 자동 간격 입력란은 실제 좌표 간격이 아니라 기준거리 kD를 그대로 표시했던 것이므로, 단일 ‘최소 파일 중심거리’ 출력으로 대체했다. 모든 파일 쌍의 실제 직선거리 중 최솟값을 표시하며, 도면에 해당 파일 쌍의 중심 연결선과 거리(mm 및 D 배수)를 표시한다. 배치 좌표·기초 크기·반력·배근 계산은 변경하지 않았다.

## 파일 배치 외곽에 따른 기초 경계 · 2026-09-15 (v74)

이 항목은 앞서 기록한 기초·기둥 중심 일치 방식과 3본 기초 크기 산정 방식을 대체한다. 사각형 기초를 유지하되, 파일군 도심과 기둥 중심만 일치시킨다. 파일 좌표의 최소/최대 X/Y에 각각 1.25D를 더해 기초 치수를 구하고 50 mm 단위로 올린다. 올림 여유는 양쪽에 절반씩 배분한다. 기초 중심은 파일 좌표 외접 사각형 중심이다.

3본, D=500 mm, k=2.5: 삼각형 변 1250 mm, 기초 2500×2350 mm, 기초 중심 Y=+180.421959 mm(기둥 원점 기준). 좌/우 연단거리 625 mm, 하/상 633.734123 mm. 5본 등 양축 대칭 배치의 크기·중심은 종전과 같다.

- 기초 자중 W는 실제 평면 중심 (ex,ey)에 작용한다. 사용 반력에는 Mxs+W ey, Mys+W ex, 계수 반력에는 Mxu+1.2W ey, Myu+1.2W ex를 적용한다. 좌표·단위 환산 후 힘과 모멘트 평형을 확인한다. 파일들은 동일 축강성이고 파일군 좌표축에서 Σxy=0인 기존 배치만 사용한다.
- 휨·1방향 전단은 각 기둥면의 양측 실제 돌출길이를 사용한다. 순하중 = 해당 파일 반력 − 해당 구역 기초 자중. 부호 반전 및 하부근만으로 해결되지 않는 경우의 판정은 유지한다.
- 기둥면 d/2 위험둘레는 이동된 기초의 네 경계 안에 완전히 들어오는지 검사한다. 뚫림의 자중 공제 면적은 실제 기초 면적을 사용한다. 편심 전단응력에는 |기둥 모멘트|+|자중 편심모멘트|를 보수적으로 전량 부담시키며, 반력에 따른 모멘트 경감이나 부호 상쇄는 인정하지 않는다. 이것은 상세 모멘트 전달 해석을 대신하지 않는 기존 보수적 예비 모델의 확장이다.
- 1방향 전단철근 격자는 실제 기초 중심으로 이동한다. 뚫림 보강은 기둥을 중심으로 배치하고, 가장 가까운 기초 경계까지의 공간으로 최대 보강 범위를 제한한다. 최외곽 무보강 검토둘레와 철근 피복도 이 경계 안에 확보한다.
- 화면은 네 방향 연단거리, 기초 중심 좌표, 계수 자중 편심모멘트를 표시한다. 하중 입력은 계속 Ps/Pu만 사용한다. 기초 외곽 및 철근/파일 도면 좌표도 실제 계산 경계와 동일하다.

KCSC KDS 14 20 70 §4.2 원문에서 사용하중에 의한 지지력, 말뚝 중심 집중반력 및 기초 절단면 한쪽 전체 하중에 대한 휨 산정 규정을 다시 확인했다. 검증에는 삼각형의 독립 기하식, 자중에 의한 1/4·1/4·1/2 파일 반력 분담, 양측 절단면 손계산, 상하 반전 대칭, 위험둘레/전단철근 경계, 기존 대칭 배치 및 지내력 기초 회귀검사를 포함한다.
