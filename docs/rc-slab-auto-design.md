# 슬래브 자동 배근 · 2026-09-15

1방향·2방향 슬래브에서 하중을 입력하면 철근 직경과 간격을 자동 제안한다. Mu·Vu 직접 입력도 유지한다. 수동 배근 입력은 화면에서 제거했으며, 기존 `RCSlabOneWay.calculate`와 `NewPrograms.slab` 검토 함수는 독립 재검증 및 호환성을 위해 유지한다.

## 배근 선정

- 공칭치수/면적은 기존 RCBeam.BARS, 휨내력은 RCSlabUplift.capacity의 변형률 적합 평형·강도감소계수·최소허용변형률을 사용한다. 반대쪽 압축철근 효과는 반영하지 않는다.
- D10·D13·D16·D19·D22·D25, 주철근 간격 100–300 mm(10 mm 단위)의 조합을 탐색한다. 조건을 충족하는 전체 철근량이 가장 작은 후보, 동률이면 넓은 간격을 선정한다. 정착·이음·겹침·절단손실·시공비를 포함한 최적화는 아니다.
- **1방향: 상·하부 주철근 공통 간격**, 면별 직경은 다를 수 있다. 배력근은 상·하부 같은 직경/간격으로 자동 설계(100–300 mm, 10 mm 단위)한다. 모멘트 없는 면도 조립을 위한 최소량을 배치하는 제안 정책이다. 기존 검토 함수의 무모멘트 면 면제 조건을 변경한 것은 아니다.
- **2방향: 상·하부 X·Y 네 위치 모두 하나의 간격**, 위치별 직경은 다를 수 있다. 각 면에서 X가 외측, Y가 내측이다. 주철근에 휨·최소량·연성·최대간격·균열제어 간격을 적용한다. 2방향의 최소량은 각 면 각 방향 ρmin·bh(1,800 mm² 완화 미적용)이다.
- 1방향은 기존 코드의 최소량 상한과 양면 합산 배력근 검사를 그대로 사용한다. 주철근 간격 min(2h,300), 균열제어 fs=2fy/3·건조/기타 환경 적용. 2방향에도 같은 간격 검사를 적용한다.
- 공칭지름과 피복을 반영하여 4개 철근층 사이의 순여유를 확인한다. 내부 골재 가정 25 mm에 따라 순간격 min=max(25,db,100/3) mm, 철근망 사이 100/3 mm 이상.
- 후보가 없으면 배근을 임의 제시하지 않고 오류와 두께/경간/하중 조정 안내를 표시한다. 휨 배근을 제안했어도 전단 부족은 미달로 표시한다. 1방향 참고두께 미달도 기존과 같이 처짐 검토 필요로 표시한다.

## 1방향 하중·지지

기존 직접강성법을 사용한다. 양단 단순, 양단 고정, 왼쪽 단순/오른쪽 고정, 왼쪽 고정/오른쪽 자유(캔틸레버)를 선택한다. 혼합 지지와 캔틸레버는 좌·우 반대 조건도 선택 가능하다. 고정은 이상적 완전 회전구속이다. D·L 등분포와 집중활하중 PL의 동시 재하, 1.4D 및 1.2D+1.6L 조합별 정·부모멘트/전단 포락을 유지한다. 실제 인접 경간과 지지부 강성의 해석은 아니다. 자세한 산식은 [기존 1방향 근거](rc-slab-oneway.md).

## 2방향 하중·해석

KDS 14 20 70 **4.1.2.2(1)**은 평형·적합 조건을 만족하는 해석법을 허용하고 강도 및 사용성 충족을 요구한다. 이 페이지는 계수표법/직접설계법이 아닌 **4변 지지 선형 탄성판 해석에 따른 휨·전단 배근 제안**이다. 사용성 판정을 완결하지 않으며 화면에 명시한다.

모델 범위:

- 사각형, 4변이 보·벽에 선지지, 장단변비 ≤2, 경간 ≤50 m. 도구 지원 두께 100–2,000 mm. 자동 해석은 추가로 h ≤ 단변/10에 한정한다(도구의 얇은 판 모델 제한이며 KDS 최소두께 조항이 아님).
- 각 변에서 수직변위 w=0, 단순은 Mn=0, 고정은 법선 회전=0. **모서리 들림도 구속**한다. 단순지지는 모서리 들림을 허용한다는 뜻이 아니다. 실제 들림 방지 정착과 지지보 전달력은 별도 설계한다.
- 일정 미균열 등방 강성, ν=0.20. 슬래브 자체의 변형만 해석한다. 실제 경계보/벽의 변형, 다경간 연속효과, 패턴 재하, 자유변, 개구부, 무량판/기둥 지지는 제외한다.
- 전면 균일 등분포 D와 L의 중력조합 1.4D 및 1.2D+1.6L. 자중을 별도로 가산하지 않으므로 D에 포함해야 한다. 단면력 직접 모드는 하중계수를 추가하지 않는다.

`rc-slab-plate.js`는 u=wDplate/q를 미지수로 ∇⁴u=1을 13점 중앙차분으로 푼다. 고스트 절점은 단순단 반대 부호 반사, 고정단 같은 부호 반사를 사용한다. 내부 양정치 행렬은 대각 전처리 공액경사법으로 상대 RMS 잔차 ≤10⁻⁹에 수렴시킨다. 24×24와 32×32 망을 비교하고 모멘트 차이가 3%를 넘으면 48×48로 세분화한다. 최종 차이 5% 초과는 결과를 내지 않는다. 비교한 두 망의 방향별 설계모멘트 중 큰 값을 사용한다. 이는 기준의 허용오차 조항이 아닌 프로그램의 수치 검증 제한이다.

판 모멘트(단위하중 해):

```
Mx/q = −(u,xx + ν u,yy)
My/q = −(u,yy + ν u,xx)
Mxy/q = −(1−ν) u,xy
```

양의 값은 하부 인장을 뜻한다. 위치마다 비틀림과 두 방향 모멘트를 함께 변환하고 그 결과를 포락한다:

```
하부 X/Y = max(0, Mx/y + |Mxy|)
상부 X/Y = max(0, −Mx/y + |Mxy|)
```

이는 직교 배근을 위한 보수적 절대 비틀림 가산법이며, Wood–Armer의 최적화 분기식을 모두 구현했다고 표방하지 않는다. 원래 Mx/My 포락에 다른 위치의 Mxy를 덧붙이는 방식이 아니다. 단순지지 판의 모서리에는 순수 비틀림으로 상·하부 배근이 필요할 수 있다. 제안 배근을 전 영역에 유지하는 범위이며 절단·정착 길이를 정하는 상세도는 아니다. 직접 입력 Mu는 이러한 비틀림 배근 요구가 이미 반영된 값이어야 한다.

1방향 전단 검토:

- 판 전단 Qx/q=−∂(∇²u)/∂x, Qy/q=−∂(∇²u)/∂y를 복원한다. 경계는 2차 편측차분, 내부는 중앙차분. 두 비교 망의 최대 절대값을 사용한다.
- 추가로 각 방향에 **전체 하중**을 싣는 1 m 보의 지점 최대 전단을 산정한다. 양단 같은 조건이면 qL/2, 단순/고정 혼합이면 5qL/8. 판 전단과 이 보 모델 중 큰 값을 각 방향 Vu로 사용한다. 이 추가값은 실제 판 반력 분배를 뜻하지 않는다.
- φVc=0.75·min(√fck,8.4)·d/6 (kN/m). 상·하부 각 면 d를 비교하고 요약은 방향별 작은 내력을 표시한다. 위험단면까지 d만큼 이동하는 저감은 하지 않는다. 모서리 집중반력 전달, 지지보 비틀림, 기둥 뚫림전단은 별도이다.

처짐·균열폭·경계보 강성에 따른 최소두께 조건은 계산하지 않는다. 화면의 “휨·전단·배근 충족”은 전체 구조설계 완료 판정이 아니다. 2방향 슬래브의 KDS 14 20 30 최소두께 검토에 필요한 경계보 강성 등은 이 입력 범위 밖이다.

## 검증

- Itasca 공식 예제의 Navier 급수에서 면내력=0으로 두고 변위 해를 독립 구현, 해석적으로 미분하여 Mx/My/Mxy 비교. 정사각형 및 장단변비 1.5·2, 중앙·1/4점·모서리 검증.
- 완전 고정 정사각판의 고전 해: 중앙 wD/qa⁴≈0.00126, 지점 Mn/qa²≈−0.0513, 중앙 M/qa²≈0.0231(ν=.3)을 ν=.2로 환산하여 비교.
- 네 변의 단순/고정 16조합 수렴, X/Y 교환 대칭, 길이 변화에 따른 M∝L²·Q∝L·u∝L⁴ 확인.
- 선정 배근을 기존 수동 검토 엔진으로 재검증. 동일 간격, 재료강도·지지조건 변경, 후보 최적성, 0하중·직접 입력 격리·전단 부족·과도하중·입력 오류 검증.
- 전체 회귀검사 304개 통과. 실제 브라우저에서 자동 계산/직접 입력, 지지조건 변경, 오류 복구, 철근 선택 확인.

## 공통 화면

`input-layout.js`: 입력 패널의 실제 폭과 현재 폰트로 제목·선택값 너비를 측정한다. 짧은 입력은 두 열, 긴 입력은 전체 폭을 사용한다. 단독으로 남은 짧은 항목도 전체 폭으로 정리한다. 동적 항목·폰트 로딩·폭 변경에 재배치한다. 입력 14px/보조설명 12px를 유지한다. 표와 도면의 grid 자식 최소너비를 0으로 두어 좁은 화면에서 페이지 전체가 밀리는 현상도 방지한다.

## 기본값 · 2026-09-15 변경

1·2방향 공통: fck 30 MPa, fy 500 MPa, 경간 3 m(2방향 X/Y 모두), 두께 150 mm, 상·하부 피복 20 mm, 기타 노출환경. 자동 제안 간격은 주철근과 배력근 모두 100–300 mm에서 10 mm 단위이며 상·하부 공통 간격 조건을 유지한다. 기준식의 배력근 최대간격 min(5h,450 mm) 자체를 바꾸는 것은 아니며, 사용자 요청의 후보 범위가 추가로 적용된다.
