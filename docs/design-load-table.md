# 용도별 설계 하중표

## 원본 및 확인 범위

- 사용자 제공 `190207-RPT-KJH-설계하중Table-Rev01.xls`를 2026-09-15 읽기 전용으로 확인했다.
- `00-사용설명서!A1`: 마감재 기준값 확인·수정, 새 재료와 하중표 항목 추가 안내.
- `01-마감표!A3:C23`: 재료 21종, 체적 단위중량 10종 / 면적당 하중 11종. 빈 선택용 `-`는 제외한다.
- `02-설계하중표!A5:J12`: 번호·용도·내용·고정하중 구성·두께·DL·LL·D+L·1.2D+1.6L·비고. A13:J54는 동일 예제 6회 반복이다. 사이트는 예제 한 개로 시작하고 추가·복사한다.
- BIFF 수식을 직접 확인했다. F6:F11은 두께가 0이면 마감표 C열, 아니면 B열 × 두께 / 1,000을 참조한다. F12는 SUM, H12는 F12+G12, I12는 1.2×F12+1.6×G12이다.
- 원본 파일은 수정하거나 저장소에 올리지 않았다.

## 구현

`design-load-table.js`는 독립 계산 모듈, `design-load-table-ui.js`는 여러 하중표와 공유 마감재 기준표를 편집한다. 이전 `NewPrograms.load`는 기존 호출 호환을 위해 남기지만 t18 화면에서 호출하지 않는다.

- 프로젝트명·용도·내용·비고·L 입력, 용도별 하중표 최대 50개, 고정하중 항목 최대 12개, 마감재 최대 100개.
- 면적당 하중과 단위중량을 명시적으로 분리한다. 원본의 빈 셀/두께 0에 따른 암묵적 전환 대신 재료의 계산 방식을 사용한다. 체적형 재료의 누락된 두께는 오류이며 0을 명시하면 하중도 0이다.
- 공통 마감재 값 수정은 모든 참조 항목에 즉시 적용한다. 별도 기준값은 사용자 재료를 추가하여 구분한다.
- 원본 기본값을 그대로 유지한다. EPS 등 면적형 값은 체적 밀도가 아니며, 물 10 kN/m³ 등은 템플릿 가정값이다. 법정 재료값/최소활하중으로 단정하지 않는다.
- 마지막 정상 입력만 브라우저 저장소 `kds-design-load-table-v1`에 보관하며, 저장 불가·불량 입력 상황을 표시한다. 저장 데이터 로드 시 전체를 다시 검증한다.
- 표의 용도·재료명 클릭은 왼쪽 편집 대상을 선택한다. 텍스트 입력은 HTML로 이스케이프한다.
- 공통 PDF 인쇄 버튼을 유지한다. 인쇄에서는 편집부·선택한 용도 그래프를 숨기고 전체 용도별 표, 프로젝트명, 계산 범위를 출력한다. 재료명은 인쇄용 일반 텍스트를 따로 제공한다.

## 산정 범위

[KDS 41 12 00 공식 기준](https://www.kcsc.re.kr/standardCode/viewer/KDS%2041%2012%2000)의 현행 공개 본문을 2026-09-15 조회했다. 1.7.1 식 (1.7-1), (1.7-2)는 이미지 수식을 직접 확인했고, 고정하중은 실제 재료의 밀도·단위체적중량·조합중량으로 산정한다는 본문을 확인했다.

- D = Σ[t(mm)/1,000 × γ(kN/m³)] + Σq(kN/m²)
- 사용하중 = D+L
- D·L만 작용하는 중력하중 비교 = max(1.4D, 1.2D+1.6L)
- 식 (1.7-1)의 F, 식 (1.7-2)의 F·T·Lr·S·R 및 기타 하중은 이 표에서 0인 범위이다. 지붕활하중·적설·강우·풍·지진까지 검토한 전체 설계하중 조합표가 아니다. 예제의 ‘지붕층’이라는 이름으로 L을 Lr로 자동 변환하지 않는다.
- 활하중은 용도별 규정 확인 후 직접 입력하며, 원본 예제 3.00을 모든 용도에 대한 기준값으로 안내하지 않는다.

## 검증

원본 첫 예제: 무근 100×23/1,000=2.30, 방수층 0.10, RC 슬래브 150×24/1,000=3.60, 천정 0.20 → D=6.20, L=3.00, D+L=9.20, 1.2D+1.6L=12.24, 1.4D=8.68 kN/m².

자동 검사: 원본 재료값, 원본 합계, 공유 재료 변경 전파, 복사본 두께 독립성, 면적/체적 단위, 무활하중 및 지배조합 교차점, 반올림, 오류 입력, 저장·복원, 화면 편집·오류 복구를 확인한다.
