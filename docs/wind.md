## 공통 계산

VH = V0·Kd·Kr·Kzt·Iw, qH = 0.5·1.225·VH²/1000 (kPa).

- 기본풍속은 직접 입력한다. 기본값 34m/s는 위치를 지정하지 않은 예시이며 실제 건설지의 기본풍속도 값을 입력해야 한다.
- 지표면조도 A/B/C/D의 zb = 20/15/10/5m, Zg = 550/450/350/250m, α = 0.33/0.22/0.15/0.10. Kr은 표 5.5-2의 상수 구간과 멱함수 구간을 그대로 적용한다. H > Zg는 중지한다.
- Kzt는 평탄지 1.0 기본, 별도로 산정한 값을 입력할 수 있다. 지형 형상으로 Kzt를 자동 산정하지 않는다.
- 주골조 Kd는 0.85~1.0, 풍관측 근거가 없으면 1.0. 외부마감은 1.0 고정.
- Iw는 특·1=1.0, 2=0.95, 3=0.90, 초고층=1.05. 입력 층수가 50 이상 또는 H≥200m이면 초고층 계수가 우선한다.
- 강도설계 1.0W, 허용응력설계 0.65W. 기본풍속에 예전 하중계수를 중복 적용하지 않는다.

## 주골조

사각형·밀폐형·높이 방향 일정 단면의 **풍방향 수평하중**이다. H/√(BD)≤8 및 H≤Zg에 한한다. X/Y는 서로 다른 풍향의 독립 사례이며 동시에 합산하지 않는다. X풍 수압면 폭 B, 풍방향 깊이 D를 Y풍에서는 서로 바꾼다. 층고는 H/층수의 균등 층고이다.

식 5.2-2: p(z)=qH·GD·(Cpe1−Cpe2). 동일 내압이 밀폐형 전체 수평합력에서 상쇄되므로 전체 합력에 별도 내압을 더하지 않는다. D/B≤1은 Cpe1=0.8kz, Cpe2=−0.5; D/B>1은 Cpe1=0.8kz+0.05, Cpe2=−0.35.

표 5.7-1의 kz는 H≤zb일 때 1. 나머지는 z≥0.8H에서 0.8^(2α), 그 아래에서 [max(z,zb)/H]^(2α). 경계에서 각 구간을 나눠 층별 F=∫pB dz 및 밑면 M=∫pBz dz를 적분한다. 구간 하단 모멘트는 그 위 분포하중의 해당 하단에 대한 모멘트이다. 표의 p는 중간높이 값이며 구간 평균값과 다를 수 있다.

n>1Hz는 식 5.6-2의 GD=1+4γ√BD. n≤1Hz는 식 5.6-1의 GD=1+gγ√(BD+φ²RD). IH, LH, BD, SD, FD, RD, ν, g 및 φ는 해당 식을 사용한다. β는 0.5/1/1.5/2에서 선택한다. 균일 질량은 M*/M=1/(2β+1); 실제 분포를 사용할 때는 사용자가 산정한 일반화질량비를 입력한다. 감쇠비는 소수(0.02=2%)이다.

**포함하지 않는 항목:** 주골조 지붕하중, 풍직각·비틀림·와류진동, 사용성, 하중조합 5.13, 부분개방형·개방형, 비정형 및 풍동시험 해석. 골바람·후류버펫팅·공기력 불안정 영향이 있으면 이 정형 건물 계산을 적용하지 않는다. 화면과 인쇄 근거에 범위를 명시한다.

## 외부마감

사각형 평면, 평지붕(경사 0°)의 외벽 일반부·모서리와 지붕 일반부·가장자리·모서리.

- H≥20m: 표 5.8-1. 외벽 정압에만 외압항 kz를 곱한다. 부압 및 지붕은 qH를 그대로 사용한다.
- H<20m: 표 5.8-2. 입력 조도 A/B/C는 C의 qH, D는 D의 qH. 저층 벽면에서 허용되는 10% 계수 감소는 적용하지 않는다.
- 피크외압계수는 원문 도표의 꺾임점 사이를 로그 면적축으로 보간하고 끝점 밖은 끝값을 쓴다. 고층 벽면: 면적 2→50m²에서 정압 1.8→1.2, 일반부 부압 −1.8→−1.4, 모서리 부압 −3.6→−2.0. 고층 지붕: 면적 1→50m²에서 일반/가장자리/모서리 −2.8/−4.6/−6.4 → −1.8/−3.2/−4.6.
- 저층 벽면: 면적 1→50m²에서 정압 2.0→1.4, 일반부 부압 −2.2→−1.6, 모서리 부압 −2.8→−1.6. 저층 평지붕: 1→10m²에서 −2.1/−3.9/−6.0 → −1.8/−2.25/−2.25. 평지붕 도표에 없는 정압계수를 임의로 만들지 않는다.
- 표 5.8-9의 개구부별 피크내압을 사용하며 외벽 정압은 음의 내압, 부압은 양의 내압을 조합한다. 한 표면의 개구부가 30%를 초과하거나 개방형이면 이 계산을 적용하지 않는다. 중간 개구부 조건 보간은 미구현이다.
- 강도설계 풍압 최소 절댓값 0.675kPa 적용 후 허용응력설계 계수 0.65를 곱한다. 하중=풍압×유효수압면적. 압력 +는 안쪽, −는 바깥쪽이다.
- a는 H≥20m에서 max(1,0.1·최소폭), H<20m에서 max(1,0.04·최소폭,min(0.1·최소폭,0.4H)). 도식은 구역 설명용이며 실제 축척이 아니다.

경사지붕, 독립지붕, 원형, 파라펫, 필로티 등 부속물과 풍동시험 결과는 포함하지 않는다.
