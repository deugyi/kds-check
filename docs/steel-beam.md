# 철골 보

2축대칭 H형강의 강축 휨과 전단을 검토한다. KDS 14 31 10 (4.3).

## 계산 엔진

이 화면의 계산은 이전 버전에서 손계산으로 대조를 마친 것과 **같은 알고리즘**이다. 화면을 다시 만들면서 `index.html` 인라인 스크립트에서 `steel-beam.js` 모듈로 옮기기만 했고, 강종표와 단면성능은 철골 기둥과 공유하도록 `steel-section.js`로 분리했다. README에 기록된 손검산(SM355 H-600×200×11×17, Lb = 3,000 mm)의 Lp·Lr·Mp·Mn·φbMn을 `tests/steel-beam.test.cjs`에 고정값으로 두어 변경이 값을 옮기면 드러나게 했다.

## 재료

- Fy는 KDS 14 31 05 표 3.4-1에서 **플랜지 두께**로 정한다. 강종을 고르면 자동 대입되고, `직접입력`을 고르면 입력값을 그대로 쓴다.
- E = 210,000 MPa는 같은 기준 표 3.5-1이다.

## 단면 구분 : KS 규격 / Built-up

**KS 규격** — KS D 3502:2022 부표 9의 열간압연 H형강 95종(화면 분류: 보용 57, 기둥용 38)을 사용한다. 조회 페이지의 `steel-spec.js` H 목록을 `steel-section.js`가 직접 읽으므로 두 목록의 치수와 필릿 반지름이 일치한다. 철골 보·기둥·합성보·SRC 기둥·BH→RH가 이 목록을 공유한다. 규격 선택 시 치수와 두께별 Fy가 갱신된다.

2026-09-14에 기존 2007판 기반 78종에서 전환했다. 치수·필릿 반지름이 같은 74종을 유지하고, 2022판의 21종을 추가하고, 2022판에 없는 다음 4종을 제외했다: H-304×301×11×15, H-310×305×15×17, H-386×299×9×14, H-404×201×9×15. 이전에 2007판만 보고 제외했던 H-304×301×11×17, H-310×305×15×20, H-506×201×11×19, H-918×303×19×37도 복원했다. 보용·기둥용은 화면상 H/B 비율 분류이며 KS의 사용 제한을 뜻하지 않는다.

**Built-up** — 용접 조립단면이다. 규격 목록이 사라지고 네 치수를 직접 넣는다.

이 구분이 곧 압연·용접 구분이므로 전단의 압연형강 면제(4.3.2.1.2.1)도 여기에 따른다. 별도의 `제작 구분` 입력은 없앴다.

## 비틀림상수 J

우선순위는 **직접입력 > 동일 치수의 기존 J 표값 > 얇은판 근사값**이다. KS D 3502:2022 부표 9에는 J가 없으므로 95종 모두의 J를 최신 KS 표값이라고 표시하지 않는다.

- **공통 74종**: 기존 KS D 3502:2007 기반 단면표의 J를 유지한다. H·B·tw·tf·r 다섯 치수가 모두 같은지 대조하여 연결한다. 화면에 기존 표 출처를 표시한다.
- **추가 21종**: J = [2B·tf³ + (H − tf)tw³]/3을 명시적으로 전달한다. 화면에 `J 표값 없음 · 얇은판 합산 (필릿 제외 근사)`를 표시한다.
- **Built-up**: 같은 얇은판 근사식을 사용한다.
- **RH + 역T 조립단면**: 원본 RH의 J를 재사용하지 않는다. 중간 플랜지를 제외한 조립 I형 검토 모델의 치수로 별도 산정한다.
- **SRC 기둥**: 현재 SRC 축력·휨 계산에는 J를 사용하지 않는다. 선택 규격의 출처와 이 사실을 표시한다.

얇은판 합산은 개방 단면의 근사식이며 필릿이 없다는 이유만으로 모든 두께와 계산에서 항상 안전측이라고 보장하지 않는다. J는 철골 보의 횡비틀림좌굴 및 합성보의 시공단계 검토에 영향을 준다. 필요하면 확인된 별도 J를 직접 입력할 수 있다. 참고: [CISC, Torsional Section Properties of Steel Shapes (2002)](https://dir.cisc-icca.ca/files/technical/techdocs/updates/torsionprop.pdf).

`hProps`에는 필릿 반지름만 주어졌을 때 사용하는 기존 필릿 보정 대체식이 남아 있다. 그러나 현재 95종 선택 경로는 모두 명시적인 J를 전달하므로 추가 21종이 이 보정식으로 바뀌지 않는다. 직접입력은 표값과 근사값 모두를 덮어쓴다.

## 단면성능

A·Ix·Iy·Sx·소성단면계수 Zx·Cw는 기존 필릿 제외 계산 모델을 유지한다. 조회 페이지의 공표 A·I 값과 계산기의 값은 구분한다. 웨브 판폭두께비에서도 필릿을 공제하지 않는다.

- Zx = B·tf(H − tf) + tw·hw²/4 (소성단면계수)
- Cw = Iy·ho²/4, ho = H − tf
- rts = √(√(Iy·Cw)/Sx)
- J는 위의 출처별 규칙에 따른다.

필릿 제외 모델을 원문보다 항상 작은 수치라고 일반화하지 않는다. 특히 H 208×202×10×16은 원문 Ix=6,350 cm⁴가 필릿 제외 기하값 6,425.3269 cm⁴보다 작은 원문 이상 항목이다. 조회 페이지는 원문과 경고를 유지하고, 계산기는 기하식으로 계산한다. KS 표의 Zx(탄성단면계수)와 엔진의 Zx(소성단면계수)도 구분해야 한다.

## 판폭두께비 (표 4.3-2)

| 요소 | 비 | λp | λr |
|---|---|---|---|
| 플랜지 | B/2tf | 0.38√(E/Fy) | 1.00√(E/Fy) |
| 웨브 | (H − 2tf)/tw | 3.76√(E/Fy) | 5.70√(E/Fy) |

**웨브가 조밀단면이 아니면 계산을 중단하고 그 사실을 표시한다.** 비조밀·세장 웨브는 4.3.2.1.1.4/5의 대상이며 이 화면에서 다루지 않는다.

## 휨강도

φb = 0.90 (4.3.1(1)). Mn은 다음 중 작은 값이다.

**횡비틀림좌굴 (4.3.2.1.1.2)** — Lp = 1.76·ry√(E/Fy) (식 4.3-6), Lr은 식 (4.3-7), c = 1.0 (2축대칭 H형강, 식 4.3-8a).

- Lb ≤ Lp — Mn = Mp = Fy·Zx (식 4.3-2)
- Lp < Lb ≤ Lr — Mn = Cb[Mp − (Mp − 0.7Fy·Sx)(Lb − Lp)/(Lr − Lp)] ≤ Mp (식 4.3-3)
- Lb > Lr — Fcr = Cbπ²E/(Lb/rts)²·√(1 + 0.078·Jc/(Sx·ho)·(Lb/rts)²), Mn = Fcr·Sx ≤ Mp (식 4.3-4, 4.3-5)

**압축플랜지 국부좌굴 (4.3.2.1.1.3(2))** — 플랜지가 조밀하면 검토하지 않는다.

- 비조밀 — Mn = Mp − (Mp − 0.7Fy·Sx)(λ − λpf)/(λrf − λpf) (식 4.3-9)
- 세장 — kc = 4/√(h/tw)를 0.35~0.76으로 제한하고 Mn = 0.9E·kc·Sx/λ² (식 4.3-10)

화면의 그래프는 Lb를 바꿔가며 Mn을 그린 것이고, Lp·Lr 위치와 이 보의 Lb를 함께 표시한다.

## 전단강도 (4.3.2.1.2.2)

Aw = H·tw, kv = 5 (수직보강재 없음, 식 4.3-89), Vn = 0.6Fy·Aw·Cv (식 4.3-85).

- 압연 H형강이고 h/tw ≤ 2.24√(E/Fy) — φv = 1.0, Cv = 1.0
- 그 외 — φv = 0.90이고 Cv는 h/tw에 따라 식 (4.3-86)(4.3-87)(4.3-88)

h/tw > 2.46√(E/Fy)이면 수직보강재 검토가 필요하다고 알린다 (4.3.2.1.2.2(2)①).

## 구현하지 않은 항목

- **웨브 비조밀·세장 단면 (4.3.2.1.1.4/5)** — 조밀 웨브만 다룬다.
- T형·ㄱ형강, 1축대칭 단면, 약축 휨, 인장역작용(4.3.2.1.2.3), 수직보강재 설계
- 처짐·진동 등 사용성, 웨브 크리플링·항복, 접합부, 내진 특수규정, 교량용 거더(4.3.3)
- Cb는 입력값을 그대로 쓴다. 모멘트 분포로부터 자동 산정하지 않는다.

`tests/steel-catalog-2022.test.cjs`는 95종 전체를 철골 보·양축 모멘트 기둥·합성보 시공단계·SRC·BH→RH·RH+역T에 전달하여 치수, J, 유한한 내력과 계산범위 밖 상태를 확인한다. 목록 통과는 모든 단면의 설계 충족을 뜻하지 않는다.
