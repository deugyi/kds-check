# 철근 규격 · KS D 3504

KS D 3504:2025 「철근 콘크리트용 봉강」 표 4(본문 6쪽, 원문 뷰어 12/30쪽)를 직접 대조한 규격 자료 페이지. 개정일 2025-06-02, 확인일 2026-09-14.

- D4, D5, D6, D7, D8, D10, D13, D16, D19, D22, D25, D29, D32, D35, D38, D41, D43, D51, D57의 19행.
- 공칭지름 mm, 공칭 단면적 mm², 공칭 둘레 mm, 단위중량 kg/m, 횡방향 리브 치수와 각도.
- 수치를 재계산하지 않고 표의 끝맺음 값을 보존한다. 특히 D57은 KS 2025 표의 **20.2 kg/m**이다. 과거 제조사 카탈로그의 20.3과 구별한다.
- 기존 RCBeam.BARS의 D10–D35 지름·면적을 대조하여 전부 일치함을 테스트한다. 기존 구조 계산 엔진과 철근 선택 범위는 변경하지 않는다.
- 원은 공칭지름 비교를 위한 그림이며 실제 리브 형상이나 리브 포함 외경을 나타내지 않는다.
- 강종별 기계적 성질, 길이/무게 허용차 표의 전재, 공급가능 규격 판정은 이번 자료 페이지의 범위 밖이다.

## 굽힘 상세 추가 (2026-09-14)
KCSC 공식 API의 KDS 14 20 50 4.1.1·4.1.2 및 표 4.1-1 수식 이미지를 직접 대조했다. KS D 3504의 재료시험 굽힘 조건과 시공 배근 갈고리는 구분한다.
- 주철근 90°: 12db 연장. 180°: max(4db,60mm) 연장.
- 주철근 내면 반지름: D10–D25 3db, D29–D35 4db, D38 이상 5db. 화면 내면지름은 그 2배.
- 스터럽/띠철근 90°: D16 이하 6db, D19/D22/D25 12db 연장. 135°: D25 이하 6db 연장.
- 스터럽/띠철근 내면 반지름: D16 이하 2db, D19 이상은 표 4.1-1. 현재 갈고리 연장 규정의 지원 상한은 D25.
- 주철근 D10 미만, 스터럽/띠철근 D25 초과는 외삽하지 않고 별도 확인으로 표시한다.
- 내진갈고리, 용접철망, 정착길이 ldh, 전체 절단길이, 옵셋/현장 재굽힘은 계산하지 않는다.
- SVG 철근은 중심선 곡률 ri+db/2, 두께 db로 생성한다. 직선 연장은 곡선 종료 접점부터 표시한다. 입구 직선은 개념도에만 사용한다.
- D10 180°의 60mm 하한, D16→D19 상세 경계, D25→D29와 D35→D38 반지름 경계를 검증했다.
