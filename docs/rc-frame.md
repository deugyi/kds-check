# RC 보 연속프레임 해석

메뉴: **구조해석 → 프레임 해석**. 1–10경간의 1개 층 RC 직사각형 보와 상·하부 기둥을 선형 탄성 직접강성법으로 해석한다. 보 내력/철근 설계 프로그램과 구분되는 해석 도구이다.

## 입력과 경계조건

- 기본 3경간, 각 6 m, 보 400×600 mm. 각 보에 Wu=30 kN/m 전 경간 하중이 있으며 수정·삭제할 수 있다.
- 콘크리트 기본 fck=30 MPa, 보통중량. KDS 14 20 10, 4.3.3의 Ec=8,500∛(fck+Δf), Δf=4(fck≤40), 6(fck≥60), 중간 직선보간을 사용한다. 지원 강도 21–90 MPa.
- 기둥 위치는 경간 수+1개. 기본 상·하부 기둥 각 3 m, 600×600 mm, 바깥쪽 끝 고정. 상부/하부만, 기둥 없이 단순지지, 직접 고정지지, 지지 없음 선택 가능.
- 모든 보 절점의 수평변위는 0. 직접 단순지지는 수직변위만 추가 구속하고 회전은 자유이다. 따라서 이 비횡이동 모델에서 힌지 지지와 수직 롤러의 별도 수평 차이는 두지 않는다.
- 기둥 바깥 끝은 수평·수직변위를 모두 구속하고 회전을 고정 또는 허용한다. 기둥 축변형은 포함하므로 기둥에 지지된 보 절점의 수직변위는 일반적으로 0이 아니다.
- 직접 고정지지는 해당 보 절점의 회전도 구속한다. 끝 절점의 지지 없음은 캔틸레버 자유단(공통 수평구속 조건 유지), 중간 무지지 절점은 보의 연속성을 유지한다.
- 기둥 없이 받치는 중간 지점도 보 단부 힌지를 별도 지정하지 않으면 모멘트를 전달한다. 보 좌·우 끝의 회전 릴리스는 개별 지정한다.
- 보 길이는 절점 중심 간 거리. 기둥 h는 프레임 휨방향 단면 높이. A=bh, I=bh³/12. 강역·편심·접합부 크기는 포함하지 않는다.
- 경간 수를 줄여 숨긴 입력은 같은 페이지 안에서는 유지되며 다시 늘리면 복원한다. 페이지 새로고침 시 초기값으로 돌아간다.

## 하중

계수된 **Wu(kN/m), Pu(kN), Mu(kN·m)**를 직접 입력한다. 자중과 하중계수는 자동으로 가산하지 않는다. 보 자중은 사용자가 Wu에 포함한다. 하나의 입력 하중 세트를 해석하며, D/L 구분·하중조합·활하중 자동 패턴 재하는 하지 않는다.

경간별 최대 30개 하중을 중첩한다.

- Wu 등분포: 전체 경간 또는 시작 a, 끝 b 지정.
- Wu 사다리꼴: a에서 0 → 증가 길이 후 최대 Wu → 일정구간 → 감소 길이 후 b에서 0. 증가/감소 길이는 비대칭 가능. 두 길이 합이 b−a이면 삼각형, 둘 다 0이면 등분포. 증가 또는 감소 길이가 0이면 해당 끝에서 수직으로 하중이 시작/끝난다.
- Pu 집중하중: 왼쪽 절점부터 거리 a. 아래 방향 양수, 위 방향 음수.
- Mu 집중모멘트: 거리 a, 반시계 양수·시계 음수. 해석 결과 M과 구분되는 외부 작용 모멘트이다.
- 전체 경간 분포하중은 경간 길이를 변경하면 작용 구간도 자동으로 바뀐다. 구간 지정 위치와 집중하중 위치는 절대거리로 유지한다. 사다리꼴 증가·감소 길이는 직접 지정한 길이를 유지한다. 경간 밖으로 벗어나면 해석을 중단한다.
- 하중은 보에 직접 작용하며 슬래브 면하중의 분담폭 자동 환산은 하지 않는다.

## 계산

각 절점은 ux, uy, θ의 3자유도. Euler–Bernoulli 프레임 요소 6×6 강성행렬을 EA/L, 12EI/L³, 6EI/L², 4EI/L, 2EI/L로 구성한다. 기둥 방향을 좌표변환하여 전체 강성행렬에 조립한다.

분포하중을 구간별 선형으로 나누고 Hermite 형상함수와의 곱을 4점 Gauss 적분해 일관절점하중을 구한다. 해당 다항식은 적분 차수 범위 안에서 정확히 적분된다. 집중하중은 형상함수, 집중모멘트는 회전 형상함수로 절점하중에 변환한다. 같은 총하중을 가진 등분포로 치환하지 않는다.

보 단부 힌지는 회전 자유도를 정적 축약한다. 강성행렬뿐 아니라 고정단 하중 벡터도 함께 축약하며, 해석 후 릴리스 회전을 복원한다. 구속을 적용한 전체 행렬을 대각 스케일링한 Cholesky 분해로 푼다. 메커니즘 또는 극단적 강성 대비로 수치적 불안정이 감지되면 결과를 제공하지 않는다. 강성이 전혀 없고 하중도 없는 고립 회전 자유도만 제거한다.

국부 단부력 r=ku−f에서 단면 전단력·모멘트를 하중 적분으로 복원한다. 집중하중에서는 V가, 집중모멘트에서는 M이 불연속이다. 좌·우 값을 구분하여 표시한다. 경간 끝에서 내부 측 극한값과 끝에 직접 작용한 하중 뒤 값은 다를 수 있다.

변위는 절점 변위만 보간하지 않고 M/EI를 적분하여 부재하중으로 생기는 내부 변위까지 복원한다. 복원된 끝 변위·회전을 요소 변위와 대조한다. 하중 변화점 및 좌·우 극한, V=0, θ=0, q=0의 구간 내 근을 포함해 최대·최소 부재력과 변위 위치를 결정한다. θ의 다항식 근은 도함수로 단조구간을 분리해 구한다.

매 해석마다 자유도 잔차와 전체 외력·반력의 힘/모멘트 평형을 확인한다. 반력 표의 보 절점 수평반력은 비횡이동 구속에 필요한 반력을 포함한다.

표준 직접강성법과 요소 정식화 참고: [MIT, Finite Element Procedures for Solids and Structures — Linear Analysis](https://ocw.mit.edu/courses/res-2-002-finite-element-procedures-for-solids-and-structures-spring-2010/dab1968e6c87110aeb83d0f4e17d75d5_MITRES2_002S10_linear.pdf). 계산 코드는 이 프로젝트에서 구현하고 아래 독립 해로 검증했다.

## 결과·부호·인쇄

- 보 M: 정모멘트 양수, 그림에서 아래쪽. V·N: 양수 위쪽. 보 N은 인장 양수.
- 수직변위: 위쪽 양수·아래쪽 음수. 계수하중에 대한 탄성변위이며 사용하중 처짐 허용치 판정이 아니다.
- 반력: 오른쪽·위쪽·반시계 방향 양수.
- 기둥 국부축: 보 접합부 → 기둥 바깥쪽 끝. 기둥 N은 인장 양수·압축 음수. 전체 단면 선형 모델이므로 상부 기둥의 인장력도 계산되며 인장균열/들림에 따른 강성 소실은 모델링하지 않는다.
- 그림에서 보/절점을 선택하여 편집한다. 보 길이는 비례 표시, 기둥은 가독성을 위해 세로 확대 개념도로 표시한다.
- M/V/δ/N 결과도와 선택 경간 위치 슬라이더, 경간별 극값, 기둥력, 반력·절점변위를 제공한다.
- 공통 PDF 인쇄는 모든 경간의 입력·하중·지지조건 요약을 펼친다. 현재 선택 결과도와 전체 결과 표를 인쇄한다. 좌측 편집기에 표시되지 않은 경간도 입력 요약에 포함된다.
