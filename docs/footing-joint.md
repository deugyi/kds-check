# 기초 수평 이어치기 검토

v77, 2026-09-17. 철근콘크리트 메뉴의 `기초 : 이어치기`.
아래층부터 2~5회 타설하는 사각 기초의 접합면 예비 검토 도구다.
기존 기초·전이보 계산기를 변경하지 않고 검증된 단면, 재령, 정착 및 파일 배치 함수를 재사용한다.

## 형식과 입력

- 지내력 독립기초: Ps/Pu, 사각 기초·기둥 치수, 허용지내력. 기둥 모멘트 0, 균일 접지압.
- 파일 독립기초: Ps/Pu, 파일 총개수·직경·간격배수·허용지지력. 기존 파일 배치 함수로 평면 크기를 결정한다. 최근접 중심간격 2.5D, 중심에서 기초 외곽까지 1.25D 이상. 파일군 도심과 기둥 중심을 일치시키며 기초 외곽 중심은 달라도 된다.
- 매트기초: 각 타설 중/양생 후 시점의 X/Y 계수 Mu(kN·m/m), Vu(kN/m)를 1 m 설계대 기준으로 직접 입력한다. Mu 부호를 유지하며 Vu는 절댓값을 쓴다. 기초 자중을 추가하지 않는다. 입력은 해당 타설단계를 반영한 별도 구조해석 결과여야 한다.

기본값: fck40, fy500, fyt500, fyd500 MPa, 3000×3000×1500 mm, 피복80 mm, 750 mm씩 2회, 20℃·차수마다7일. X/Y 상하부 D25@150, 기존 관통 D13 2다리/400×400 mm 격자, 추가 D16. 모두 예제 입력이다.
주철근은 실제 시공할 배근을 입력해 검토한다. 자동 제안 대상은 추가 접합면 다월바다.

## 단계 및 강도

각 차수 양생 후와 다음 차수 타설 중을 구분한다. 새 콘크리트는 하중만 증가시키고 내력 높이·강도에는 산입하지 않는다. 타설 중에는 직전 양생 시점의 확인 강도와 기둥 축력 전달 비율을 유지한다. 1차 타설 중은 굳은 단면이 없어 지반/거푸집/동바리 별도 검토로 표시한다.

발현강도는 기존 ConcreteAge의 온도·누적재령 간편 모델 또는 시점별·타설층별 직접 입력이다. 간편 모델은 평균강도에서 Δf를 공제하고 fck 이하로 제한한다. 21~90 MPa 밖의 내력 적용 강도나 미확인 강도는 계산 보류이며 성공 판정하지 않는다. 시험강도를 대체하는 보증값이 아니다.

## 독립기초 반력 및 단면력

기초 자중 W=24AH(kN), 서비스 1.0W/계수1.2W. 입력 Ps/Pu에서는 자중을 제외한다.
지내력 기초는 균일 접지압에서 분포 자중을 차감하면 순반력 q=단계Pu/A이다. 기둥면 밖 캔틸레버 M=q l²/2, 접합면용 거리 평균 V=q l/2, 수직 전단용 V=q max(l−d,0). 짧은 방향 중앙대 휨에는 기존 직사각 기초의 2β/(β+1)를 적용한다.

파일은 동일 축강성을 가정한다. 반력은 N/n+Mx y/Σy²+My x/Σx²이며 기초 외곽 편심에 의한 자중 모멘트를 포함한다. 파일 반력 합과 모멘트 평형을 시험한다. 인발은 지원하지 않는다.
접합면용 V는 기둥면부터 외곽까지 단위폭 전단력 크기 |V|를 구간 적분한 거리 평균이다. d 떨어진 수직 전단 검토의 반력 저감을 접합면 수요에 재사용하지 않는다. M은 파일 위치·외곽·기둥면과 V=0 지점을 검색한다. 중간층 상부 철근이 없는 시점에 부휨이 발생하면 별도 확인으로 표시한다.

## 접합면 전단과 보강

층별 Ec로 환산한 비균열 콘크리트 전체 단면에서 τ=VQ/(Ib)를 계산한다. 1 m 폭, mm, MPa 단위를 사용한다. 서로 다른 강도의 Ec는 기존 방식 Ec=8500∛(fc+Δf)로 산정한다. 접합면 응력의 단면 특성은 철근량 및 휨 부호에 의존하지 않는다. τu=max(τX,τY)로 방향별 평균전단 응력 중 큰 값을 사용한다. 사용자 지정 평균전단 모델이며 국부 최대응력 검토를 뜻하지 않는다.

[KDS 14 20 22 4.6](https://www.kcsc.re.kr/standardCode/viewer/KDS%2014%2020%2022)의 원문은 2026-09-17 KCSC 표준 상세 API와 수식 이미지를 직접 대조했다.

- 접합면에 수직인 철근 Vn=μAvf fy, φ=.75, fy≤500 MPa.
- 보통중량 콘크리트: 레이턴스 제거·약6 mm 요철의 거친 면 μ=1.0, 거칠게 하지 않은 면 μ=.6.
- 거친 면의 설계응력 상한: φ min(.2fc, 3.3+.08fc, 11) MPa.
- 거칠게 하지 않은 면: φ min(.2fc, 5.5) MPa.
- fc는 활성 타설층 중 최솟값을 사용한다. 영구 순압축력은 기본 미반영이며, KDS 4.6.2(6)에 따라 최소 순압축응력을 직접 입력하여 선택적으로 반영할 수 있다. 순인장·박리의 별도 철근은 이 도구의 범위 밖이다.

기존 관통철근 Avf=격자당 다리수×철근면적×10⁶/(sX sY), mm²/m². 양측 직선 정착이 충족되는 경우만 내력에 산입한다. 부족분은 선택한 다월바의 X/Y 동일 정방 격자를 @600부터 @100까지 10 mm씩 검색한다. 콘크리트 상한 초과는 철근 추가로 해결하지 않는다.

정착은 기존 RebarDevelopment의 [KDS 14 20 52 4.1.2](https://www.kcsc.re.kr/standardCode/viewer/KDS%2014%2020%2052) 직선 인장철근 식을 사용한다. 무도막 수직철근, λ=1, Ktr=0. 기존 철근은 현재 굳은 전체 높이의 접합면 양측을, 추가 다월바는 각각 인접 타설층 안의 확보길이를 확인한다. 갈고리·기계식 정착은 별도다. 모든 검토 시점에서 필요한 공통 간격을 정한 뒤 그 간격으로 각 시점의 정착길이를 재검사한다. 하나라도 강도/상한/정착/간격 조건이 미확인 또는 불충족이면 종합 배근 그래픽은 보류한다.

## 해석 및 상세 범위

휨은 입력한 주철근과 최소 발현강도를 이용한 1 m 폭 단면 검토다. 최상부 철근은 최종 타설 양생 후에만 반영하고 중간층 상부 철근은 가정하지 않는다. 수직 전단은 콘크리트 내력만 표시한다. 기둥 주변 뚫림은 내부 d/2 사각 위험둘레가 확보되는 독립기초에서 기존 기초 함수와 같은 방식으로 확인한다.

파일캡 스트럿-타이, 파일 주변 국부 뚫림/군파일 둘레, 매트 기둥 주변 뚫림, 주철근 정착, 기둥 지압, 침하, 동바리, 수화열, 수밀성, 크리프·수축·슬립을 포함한 정밀 타설단계 해석은 별도다. 수직 전단 철근과 접합면 철근의 저항을 동시에 중복 사용하는 설계도 이 도구에서 승인하지 않는다. 전체 기초의 적합성 판정이 아니다.

단면은 실제 비율로 그리되 철근은 일부를 표시한 개념도다. 타설층·철근·파일을 선택하면 강도, 정착, 배근 또는 반력을 표시한다. 도면의 종합 다월바 간격은 모든 시점의 포락값이며 단계별 표의 개별 소요 배근과 구분한다. 공통 PDF 인쇄 도구를 사용한다.

## v78 기준 정리 · 2026-09-20

KCSC 원문에서 KDS 14 20 22 4.6.2(6), 4.11.2, 4.11.3(3), 4.11.7 및 KDS 14 20 20 4.2.2(3)을 재확인했다.

- 직접 뚫림은 vu=Vu/(b₀d), φvc=.75vc로 검토한다. 측면 편심전단강도 v_nT에 쓰는 0.63√fck 및 0.25fck를 직접 뚫림 상한으로 혼용하지 않는다.
- 기존 M c/J 응력 가산은 제거했다. 자중 편심모멘트가 있으면 직접 뚫림 결과와 Mx/My를 별도로 표시하고, 4.11.7의 φMn=φf MF+φv MS+φv MT 및 양방향 상호작용 검토를 요청한다. 해당 조항 전체를 구현한 것으로 판정하지 않으며 전체 뚫림 `ok`는 false이다. 반력과 휨·일방향 전단에는 자중 편심을 계속 적용한다.
- 영구 순압축 옵션은 모든 검토 시점·접합면·검토영역에서 성립하는 하한 σn(kPa)을 직접 입력한다. 국부 기둥 축력이나 계수 접지압 Pu/A를 자동 전용하지 않는다. 활하중, 양압력, 박리 가능성 등을 고려한 영구 순압축만 인정한다. 기본 0, 미반영이며 근거가 확인되지 않으면 미반영을 유지한다.
- 순압축에 의한 설계내력 증분은 φμσn(MPa), 추가 철근량은 max[0,(τu−기존철근내력−φμσn)10⁶/(φμfy)] mm²/m²이다. 콘크리트 상한은 그대로다. 기존철근과 순압축 기여는 서로 다른 열로 표시한다.
- τu=√(max|τX|²+max|τY|²)는 방향별 최대값의 포락이며 같은 위치 응력값이라는 뜻이 아니다. 같은 지점에서 τX(x,y),τY(x,y)를 평가하는 판/접촉 해석은 미구현이다. 임의 √2 저감은 하지 않으며 출력 바로 아래에 이 한계를 명시했다.
- 기초판 철근 간격의 규정상 상한은 min(3h,450) mm다. 기존에 사용자가 정한 주철근 입력/자동 후보 및 다월바 제안 범위 @100~@300은 별도 설정이며 확대하지 않았다.

추가 검증: 압축응력 단위와 φμ 계수, 옵션 해제, 음수/비유한 입력, 콘크리트 상한 유지, 추가 다월바 불필요 전환, 직접 뚫림과 편심 검토 분리, 화면의 반영 여부와 오류 복구.


## 추가 다월바 물량 · v81 (2026-09-21)

각 접합면의 모든 검토 시점을 포락한 공통 배근을 한 번씩 산출한다. 단계별 물량을 중복 합산하지 않는다. 기존 관통철근과 주철근은 포함하지 않는다. 미리보기 시점을 바꿔도 총 물량은 같다.

- 지내력·매트는 입력 평면, 파일은 자동 산정한 실제 기초 평면을 사용한다. 1 m 설계대 해석력으로 검토하는 매트도 물량은 입력한 전체 사각 평면에 대한 값이다.
- 다월바 중심 이격 e=피복+db/2. nx=ceil[(Bx−2e)/s]+1, ny=ceil[(By−2e)/s]+1, N=nx ny. X/Y 방향 철근을 따로 두는 것이 아니라 격자점당 수직 다월바 1본이다.
- 실제 등분 간격 sx=(Bx−2e)/(nx−1), sy=(By−2e)/(ny−1)이며 제안 간격을 넘지 않는다. min(sx,sy)에서 모든 해당 시점의 정착을 재확인한다. 양쪽 정착길이 최댓값을 각각 10 mm 올림하고 인접층의 확보길이를 넘지 않을 때만 물량을 제시한다.
- 1본 길이=하부+상부 정착길이, 총길이=N×1본 길이/1000 (m). 공칭단면적(mm²)×0.00785=kg/m(밀도7,850 kg/m³), 총길이에 곱해 kg과 tonf(표준중력 기준, kg/1000)로 표시한다.
- 공통 배근의 강도·정착·간격이 미확인 또는 불충족이면 해당 행은 산출 보류(null)이며 0본으로 처리하지 않는다. 일부만 산출되면 전체 합계가 아닌 소계로 명시한다. 추가 다월바가 불필요하고 검토가 완료된 면만 0본이다.
- 전면 균등 배치 개산이다. 기둥·파일 위치를 공제하지 않으며 절단 손실, 가공 할증, 갈고리, 철근 간섭 조정 물량은 포함하지 않는다. 서로 다른 접합면의 다월바는 독립 철근으로 산출하고 관통 장대근으로 합치지 않는다.

## 추가 다월바 간격 상한 · 2026-09-22

사용자 요청으로 추가 다월바 자동 후보를 @600~@100, 10 mm 단위로 확대했다. 소요 전단마찰 철근량과 인접 타설층 양측 정착을 만족하는 가장 넓은 간격을 선택하고, 모든 시점의 요구를 포락한다. 물량은 실제 기초 평면에 맞춘 격자 개수와 실제 간격으로 정착길이를 재확인하여 산정한다. @600은 자동 제안 후보의 상한이며 모든 입력의 배근을 @600으로 고정하지 않는다. 주철근 @100~@300과 별도 기초 전단보강 모듈의 기준상 간격 제한은 유지한다.

## 비균열 접합면 모델 · 2026-09-22

사용자 지정으로 접합면 응력은 비균열 환산단면만 사용한다. 기존의 비균열·균열 중 큰 값 선택을 제거했다. 화면에 이 가정을 명시하며 실제 균열 발생 여부를 판정하는 기능은 아니다. X/Y 최대값 조합, 전면 동일 격자, 추가 다월바 @100~@600 및 정착·물량 계산은 유지한다. 기본 예제는 기존에도 비균열이 지배하므로 이 변경만으로 응력이나 물량이 감소하지 않는다.

## 거리 평균 전단력과 방향별 큰 응력 · 2026-09-22

사용자 지정으로 지내력·파일 기초 접합면 설계의 V를 각 방향 기둥면~외단의 거리 평균 |V|로 변경한다. 양측 돌출부 길이는 각자 적용하며 양측 평균 중 큰 값을 사용한다. 지내력 균일 순반력은 q·l/2, 파일은 반력 불연속 사이의 선형 V를 절댓값 적분하고 영점에서 분할하여 부호 상쇄를 막는다. 파일 지점 자체의 점프는 적분 면적에 영향을 주지 않는다.
